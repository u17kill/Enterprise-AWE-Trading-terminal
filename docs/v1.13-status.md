- 用户施工图：[市场总览完整需求](market-overview-requirements.md)。[实施计划](superpowers/plans/2026-11-24-market-overview.md)。

## 已实现

- 首页替换旧 Dashboard，28 项初始清单、品种筛选、搜索别名、增删、可见槽位拖动排序；排序不取新行情。
- 手动自选与卫星仓独立。自选可搜索、批量导入、板块下拉归类、同市场跨板块拖动与板块列排序；持仓视图只读，保留未接入与未取到两类状态、观察区、脏标记。
- 判断文件缺失时显示说明；重读判断不取行情，跨日同时显示判断日期与行情日期。有限着色标签安全渲染，不注入 HTML。
- /api/market、config、refresh、brief、search；刷新／配置互斥，刷新重入 429，判断重读占用 503；配置和缓存分离、原子写入，非债券缺卡刷新失败时不覆盖旧行情。收益率可回退旧缓存并披露。
- 持久目录：`~/Documents/Codex/.awe-terminal-data/market/`。核心仓和卫星仓原文件均只读。本机迭代不重置配置。损坏配置不静默覆盖。

## 数据与运行边界

- 今日市场不自动编写判断；需在持久目录 `market/brief.json` 写入人写内容。未生成不是行情故障。
- 长桥必须在当前站点授权；本轮长桥优先分支完成代码接入，尚待用户授权后端到端核验。公开来源完整取数已验证。
- 部分市场使用 ETF 或期货代理，卡片角标与页脚披露；非交易时段不是逐笔实时价格。
- Python 依赖：scripts/market-engine/requirements.txt；默认解释器 `.local/market-venv/Scripts/python.exe`，可用 AWE_MARKET_PYTHON 指定。westock CLI 需要在本机存在；不是对 8765 服务的代理。
- 全局其它频道更新不调用市场刷新。未新建跨频道 /api/refresh，以免覆盖现有站点职责。
- Next.js 构建提示当前依赖版本有已知安全问题，建议后续单独升级；本次未混入框架升级。
- 用户验收状态：待验收。不得将程序测试等同于用户验收。
