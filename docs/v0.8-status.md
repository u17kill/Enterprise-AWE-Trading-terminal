# V0.8 需求与进度记录

## 需求

在左侧新增“期权计算”模块：十二种常见策略的说明、买卖腿、固定示例盈亏图，以及与所选策略对应的手动输入计算器。用户输入股价、执行价、权利金和张数后，查看何时盈利、何时亏损及盈亏平衡点。用户在初稿十种之外明确追加**衣领式**与**铁鹰式**，两种均计入 V0.8 首批范围。

用户已确认十二种策略的设计，首版只算**到期日盈亏**；到期前估值暂不做。策略、界面布局、计算及校验口径见[设计文档](superpowers/specs/2026-10-25-v08-options-calculator-design.md)，代码见[草稿 PR #11](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/11)。

## 数据与边界

- 本模块使用手动输入，不读取实时期权链，不连接交易接口。
- 策略教育参考[期权行业委员会策略目录](https://www.optionseducation.org/strategies/all-strategies-en)；图形由本项目公式绘制，不复制外部图片。
- 示例“熊市看涨价差”由卖出较低执行价 Call、买入较高执行价 Call 组成；用户提及的买 Put、卖 Call 是另一种组合，设计中已单独说明。
- 衣领式含股票、买 Put、卖 Call，计算器单独输入股票成本价；铁鹰式含四条期权腿，核验四个执行价的顺序和不等宽两翼的风险。教育来源：[衣领式](https://www.optionseducation.org/strategies/all-strategies/collar-protective-collar)、[铁鹰式](https://www.optionseducation.org/strategies/all-strategies/short-condor)。
- 输入假定所有期权腿同一到期日、相同张数和乘数；持股策略按每张合约对应股数持有股票。结果不含手续费、税费、滑点、股息、提前行权或保证金要求。图上“当前股价对应盈亏”指假设到期股价等于当前输入股价时的结果，不代表今日盈亏。

## 交付与验证

- 新增 `/options` 页面和全站导航入口。十二张策略卡展示组成腿、简述及由同一公式绘制的固定示例曲线；选择卡片后进入该策略的手动输入与动态盈亏区。
- 支持当前股价、执行价、每股权利金、张数、每张对应股数；备兑看涨与衣领式另有独立股票成本价。输入变化即时更新曲线、到期盈亏、最优/最差结果、净权利金和盈亏平衡点。铁鹰式额外展示上涨/下跌两侧极端结果，不等宽时提示风险不同。
- 无效输入和错误的执行价顺序会停止展示计算结果；净收支方向与常见策略不同则提醒，但仍按用户输入计算。可以重置示例。每种策略有教育来源链接。
- 独立复核后补齐：小额盈亏保留小数、不再显示为 `$0`；输入错误显示在对应字段旁并提供辅助说明；动态曲线下方标出执行价、当前股价、盈亏平衡点，理论上无上限时显示延续提示。
- 验证：30 个测试文件、121 项测试通过；全项目 ESLint 与 Next.js 16.4.2 生产构建通过，`/options` 已生成页面。本地浏览器确认策略目录、铁鹰式切换、无效执行价提示、衣领式成本价变化，浏览器无报错。窄屏布局按 CSS 断点实现，尚未在小视口浏览器中实测。
- 2026-10-26 本地访问修复：原先的 `127.0.0.1:3100` 预览会随临时开发进程退出，浏览器因此显示连接失败。已在这台 Windows 电脑上注册登录后启动的计划任务 `AWE Trading Terminal Local Preview`，调用仓库内 `scripts/start-local-preview.ps1` 构建并以正式模式运行，仅绑定本机地址。手动运行该计划任务后，确认构建成功、任务保持运行，并在浏览器刷新 `/options` 成功。尚未通过实际重启电脑验证登录触发。电脑必须开机且用户已登录；服务重启会清除内存中的 Longbridge 授权会话，需要重新连接。
