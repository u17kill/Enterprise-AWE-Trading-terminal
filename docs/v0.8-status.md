# V0.8 需求与进度记录

## 需求

在左侧新增“期权计算”模块：十二种常见策略的说明、买卖腿、固定示例盈亏图，以及与所选策略对应的手动输入计算器。用户输入股价、执行价、权利金和张数后，查看何时盈利、何时亏损及盈亏平衡点。用户在初稿十种之外明确追加**衣领式**与**铁鹰式**，两种均计入 V0.8 首批范围。

用户已选择首版只算**到期日盈亏**；到期前估值暂不做。候选策略、界面布局、计算及校验口径见[设计草案](superpowers/specs/2026-10-25-v08-options-calculator-design.md)，并已放入[草稿 PR #11](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/11)。设计待用户确认，尚未开始产品代码。

## 数据与边界

- 本模块使用手动输入，不读取实时期权链，不连接交易接口。
- 策略教育参考[期权行业委员会策略目录](https://www.optionseducation.org/strategies/all-strategies-en)；图形将由本项目公式绘制，不复制外部图片。
- 示例“熊市看涨价差”由卖出较低执行价 Call、买入较高执行价 Call 组成；用户提及的买 Put、卖 Call 是另一种组合，设计中已单独说明。
- 衣领式含股票、买 Put、卖 Call，计算器需单独输入股票成本价；铁鹰式含四条期权腿，核验四个执行价的顺序和不等宽两翼的风险。教育来源：[衣领式](https://www.optionseducation.org/strategies/all-strategies/collar-protective-collar)、[铁鹰式](https://www.optionseducation.org/strategies/all-strategies/short-condor)。
