# V0.3 持仓地图

根据用户提供的 full satellite 示意图，将持仓地图改成横向“进攻 / 均衡 / 防御 → 主题”、纵向“美国 / 中国 / 日韩台印 / 欧洲”的矩阵。初始录入了图中的标的与金额备注，可逐项修改。

- 灰色：已持仓；黄色：暂未持仓、观察；绿色：计划加仓。
- 策略、主题、地区、标的均可新增、编辑和删除。删除策略、主题或地区前提示将一并删除其标的。
- 编辑结果自动保存在浏览器的 V0.3 独立存储键，可导出、导入 V0.3 备份；旧 V1.3 数据不覆盖，若检测到旧数据，可在页面下载旧版备份。
- 图中数字以文本形式保存，不按实时价格、股数或投入成本解释。期权相关文字仅作为示意图备注录入。
- 初始示意数据写入源码，随公开仓库和 PR 可见；用户在浏览器后续修改的内容仍只存本地。
- 宽表格在窄屏可横向滚动。

验证：73 项测试、ESLint、Next.js 生产构建通过。尚待用户在本地页面核对布局与图中每项内容。
