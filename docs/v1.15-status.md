六页独立刷新、独立状态、独立文件锁。相同页面更新中再次请求返回 429；不同页面可同时发起，底层 westock 调用共享限频队列。取数先在临时目录生成，验证成功后原子替换本页快照；失败不覆盖旧结果。后台页完成不会把当前页切走。支持导出含六页图表的单文件离线快照；离线按钮明确说明无法取新数据。

## 本机数据与运行

持久数据默认位于 `C:/Users/T14s/Documents/Codex/.awe-terminal-data/temperature/`；可用 `AWE_PORTFOLIO_DATA_DIR` 改其父目录。该目录独立于代码和构建产物，因此刷新、重新构建、重启不会恢复初始值。请备份整个目录，尤其恐惧贪婪及沽空归档；不要仅备份源码。

初始公开历史序列从参考项目白名单迁入，来源记录保存在本机 `import-provenance.json`，随后已逐页真实更新。运行快照不提交 GitHub。新机器不会自动拥有本机历史；需要迁移该数据目录，或重新抓取可重建序列。CNN 和沽空逐日归档不能承诺事后完整重建。

服务端需要 Python（pandas、numpy、requests）及已配置的 westock CLI。默认 Python 为项目 `.local/market-venv/Scripts/python.exe`，也可用 `AWE_MARKET_PYTHON` 指定。依赖均在服务端运行，凭据不进入浏览器。可选的两融观察依赖额外数据环境，不作为缺失时的伪造分数来源。

本机验收预览：`http://127.0.0.1:3128/canary/momentum`。代码发布与本机历史备份是两件事。

## 修复与口径适配

- A 股“空仓检验/仓位规则”按用户确认改为“状态检验/观察条件”，展示事实状态，不输出机械仓位指令。
- 合成分数不再冒充经验历史分位；单列由完整序列计算的历史排名，原评分公式保持。
- 修复缺失广度字段被转成零的问题；核心字段不足直接拒绝本次更新，保留旧快照。
- 港股沽空有效样本为零时显示降级和原因，不将零样本呈现为正常比例。
- 修复 CNN 归档路径以及覆盖风险；发布前验证旧归档键未丢失，并保留备份。
- 亚太刷新独立维护并更新两条基准历史；节假日只在有效区间内对齐，基准尚无对应日期时抑制该比较。各市场曲线使用自己的交易日，不套用日本交易日。
- 修复行业/概念切换无效、亚太基准选中状态不一致、后台刷新把用户切回旧页。
- 历史统计的区间、样本数与 IC 来自快照，移除渲染中的固定当前统计。来源日期与抓取时间分开。

## 数据与技术限制

六页分数口径各自独立，不计算跨市场统一总分。ETF 代理不等于原始指数。缺失估值字段保留带原日期的可用值或明确缺项，不补造数据。legacy 拥挤度回退标明口径。页面过旧提示按四个自然日判断，并非交易所日历精确计算；具体日期以各区来源为准。

公开源可能限频、缺历史或延迟；板块实时观察有自己的时间戳，不能与收盘归档视为同一时点。刷新耗时受共享源队列影响，失败保留旧值不代表已获取最新。暂不调整已通过验收的其他模块。

构建仍报告既有 Next.js 版本安全升级提醒，以及服务端 Python 路径的动态文件追踪警告；本期未进行框架升级。正式对外部署前需另行处理版本安全升级与部署打包范围。
