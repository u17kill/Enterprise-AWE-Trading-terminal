# V0.7 需求、交付与修复记录

设计讨论中：[大佬持仓设计稿](superpowers/specs/2026-10-25-v07-leader-holdings-design.md)、[草稿 PR #10](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/10)。

## 当前状态

用户提出增加“大佬持仓”模块，以卡片展示核心机构的最新公开 13F 持仓、季度变化和提交日期。名单扩至 29 家，按价值与质量、主动与特殊机会、成长与科技、宏观与多策略四组浏览。目录与右侧详情交付后，用户测试发现除查诺斯之外都只写“等待申报数据”，要求先展示已有公开季度，再用按钮核对新申报。本次修复已为 29 家加入最近一次可查的公开 13F 快照，并启用手动更新。

本地服务端只读核验 SEC 接口及原始文件时均收到 HTTP 403。按用户先核验备用通路的决定，改由 [13f.info](https://13f.info/) 的公开目录与持仓转录提供可运行数据；详情保留每期准确的 SEC 原件链接。29 家均取得快照；潘兴广场 2026 Q2 的 13F-NT 沿明确列出的母公司 Pershing Square Inc 申报；Citadel 最近一期为修正申报。第三方转录并非 SEC API 的原始返回，应以 SEC 原件复核重要数字。

页面沿用浅色工作台；分组标签和搜索浏览 29 家机构，点击卡片在右侧打开详情，手机用全宽面板。卡片显示报告季度、非期权证券数量、申报表总值及前三项；详情显示报告期、提交日、最多 12 项非期权证券、期权数量和来源链接。旧申报醒目标记“历史申报”。

范围调整：用户决定 V0.7 聚焦 13F，不加入做空研究机构或报告。新增 Jim Chanos 的 Chanos & Co LP（原 Kynikos，CIK 0001446440）为第 29 家机构，归入宏观与多策略。当前核实到的最后一份 13F 报告期为 2023 年第三季度，必须标记为历史申报；只展示 13F 所含多头及可报告期权，不展示无法从 13F 获得的空头仓位。其他做空机构留待后续版本讨论。

## 后续工作与限制

- 当前只保存每家最近一期的前 12 项非期权证券，未取全量详情或相邻两期；季度增减、新进、退出及自动事实摘要尚不可计算，页面明确标示。
- “我的评论”尚未实现。SEC 直连仍受本地 HTTP 403 限制，未来可补直接解析原件的路径。
- 13f.info 的转录百分比按申报表总值展示；含期权时不代表纯多头权重。申报表总值也可能含期权条目。13F 不披露空头及完整基金组合，不能理解为今日仓位。

## 已实现的页面阶段

- 29 家已核实 13F 申报主体目录，四组切换、中英文/CIK 搜索和右侧详情面板；移动端详情改为全屏。
- 查诺斯的 Chanos & Co LP 标为“历史申报 · 2023 Q3”，详情列明 2023-09-30 报告期、2023-11-14 提交日，并依据 SEC 信息表展示该期 7 项非期权证券（申报市值合计 3,865,862 美元）。占比只以这 7 项为分母；申报中的期权条目单独说明，不当作股票空头或当前仓位。
- 页面阶段曾在未接通数据时显示空状态，更新按钮禁用；用户测试指出已有公开申报也应展示，见下方修复。V0.7 不含做空研究。
- 窄屏浏览器原本隐藏侧栏导航，已改为可横向滚动的导航；本地开发配置允许项目惯用的 `127.0.0.1` 地址加载交互资源。

## 页面阶段验证

- 机构目录、查诺斯历史信息表和页面交互测试通过；全量测试 27 个文件、102 项通过。原 V0.3 持仓地图测试在并行执行时两次超过默认 5 秒，单独执行正常，已把该项测试的超时阈值设为 15 秒；全量复测通过。
- ESLint 和 Next.js 生产构建通过；构建生成 `/holdings` 路由。本地预览返回 HTTP 200，页面 HTML 包含“大佬持仓”和 Jim Chanos。
- 这些验证只覆盖页面目录与空状态；真实 SEC 持仓、更新和季度比较仍未交付。
- 在 650px 宽的本地浏览器预览中，已实际从 `127.0.0.1:3100/holdings` 搜索 Chanos 并打开详情，核对 7 项历史持仓、关闭按钮、SEC 链接与窄屏导航。
