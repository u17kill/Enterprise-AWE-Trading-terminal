## 当前状态

用户提出增加“大佬持仓”模块，按价值、宏观、激进科技分类，以卡片展示核心机构的最新公开 13F 持仓、季度变化和提交日期。已选择直接读取 SEC 原始申报；自动事实摘要与可编辑评论并存。初始名单补充景林资产、但斌的东方港湾、Michael Burry 的 Scion 及 Paul Tudor Jones 的 Tudor Investment，共十二家，均找到对应 SEC 申报主体。Scion 最后核实的公开 13F 为 2025 年第三季度，页面不得将其称为当前仓位。详细页面和数据边界待用户确认后实施。

本地服务端只读核验 SEC 接口及原始文件时均收到 HTTP 403。已核验的免密钥备用接口均无法覆盖全部十二家；另一接口实际要求 API key。“更新持仓”的可运行数据通路仍需确定。设计稿列出这一接入限制，尚未开始产品代码。
