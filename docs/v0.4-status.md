# V0.4 需求、交付与修复记录

详细需求与设计：[V0.4 财经日历设计](superpowers/specs/2026-10-24-v04-financial-calendar.md)。实现与讨论：[GitHub PR #6](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/6)。本版先做财经日历；用户提出的第五个模块待后续确定。

## 需求

- 左侧新增财经日历，以月历观察未来的重要产业大会、国际政治经济峰会、科技公司活动、重点财报、央行会议和宏观指标。
- 覆盖美国、中国和日本等市场的重点事项；每条有来源，日期未公布不得猜测。
- 复用长桥连接，在用户点击更新时获取当月的财报及经济数据；不持续轮询。

## 已交付

- 月历、事件分类、选日详情、官方来源链接和“日期待公布”观察清单。
- 官方确认/暂定的 CES、APEC、2026/2027 G20、NVIDIA GTC、COMPUTEX、美联储 FOMC 会议，以及 Apple、Sony、Toyota、任天堂、软银、联发科、鸿海、港交所和腾讯已公布的财报日程作为种子事件。近期重点财报在月历上方单独列出，点击可直达当天详情。
- 服务端调用 Longbridge `finance_calendar`，筛选美、中、港、日的重要公司财报与高重要度经济指标，显示数据商来源和最近更新时间。部分市场失败会说明缺口。
- 每月更新结果保存在当前浏览器；切换页面后恢复。失败不覆盖之前成功的结果。Longbridge OAuth 凭据仍只在服务端。
- 总览看板、持仓地图和图表空间均可跳转财经日历。

## 数据边界与后续

- 官方事件目前是带来源链接的人工核实清单；更新按钮只更新长桥财报/宏观数据，不自动爬取产业大会、峰会或产品发布会。
- 长桥对日股及中港财报的覆盖可能不完整；重点公司的已公布日期使用公司官方投资者日程补足。事件名称在不同市场或双重上市时可能重复，后续可继续校准。
- 财报时间可更改，数据商日期和官方公告冲突时应以官方公告为准。官方日期待公布的活动只在观察清单。
- 用户尚未给出另一个财经日历网站地址；收到后评估合法性、更新频率及稳定性，再决定是否接入。
- 当前长桥 `finance_calendar` 未提供台股市场参数，台湾龙头财报优先采用公司投资者日程。对尚未公布的台积电下一次季度财报，只列入观察清单。

## 本版本修复

| 问题 | 原因与改动 | 验证 |
| --- | --- | --- |
| 官方财报日期与长桥日期可能同时出现 | 同一公司相近日期的财报以公司官方日程为准，隐藏相冲突的数据商条目 | 新增冲突合并测试 |
| 月末财报可能因市场当地日期跨月而遗漏 | 服务端查询扩至目标月份的前后各一个边界日，再按当地日期归月 | 跨月解析及服务端请求边界测试 |
| 月历只有宏观指标，核心公司财报日期缺失 | 长桥整月财报查询漏掉了周查询可返回的微软、谷歌、亚马逊等条目；改为每次最多七天的分段查询并去重，同时增加“近期重点财报”日期速览 | 对比长桥整月与分周结果；新增分段查询回归测试 |
| 台湾、港股与日本核心公司覆盖不足 | 核对并录入 Apple、Sony、Toyota、任天堂、软银集团、联发科、鸿海、港交所和腾讯已公布的日期；未公布的台积电后续日期不猜测 | 官方 IR 页面逐项核对；种子日期测试 |
| 点击财报速览后详情被之前的分类筛选隐藏 | 跳转日期时同步切换到“重点财报”；速览不截断后排的日、台、港股日期 | 组件交互回归测试 |

## 验证

全套 84 项测试（并发数限制为 4）、ESLint、TypeScript 类型检查、Next.js 生产构建通过。通过已连接的 Longbridge MCP 实际查询验证了 `finance_calendar` 的美股财报分周查询、宏观数据和 CN/JP 市场参数。尚未在用户浏览器完成 Longbridge 授权后的页面级人工验收；请在 `/calendar` 点击“更新日历”查看本月结果。
