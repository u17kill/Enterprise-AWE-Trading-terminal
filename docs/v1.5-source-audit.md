## 本轮实测

使用当前 Longbridge 连接的日线读取，要求 320 根已收盘常规时段日 K，并仅统计根数、首尾时间和非零成交额。A 股 `000688.SH`、`399006.SZ`、`000300.SH`、`000922.SH` 与美股 `QQQ.US`、`SOXX.US`、`SPY.US`、`DIA.US` 各返回 320 根，成交额字段均非零。A 股末根为 2026-10-29 对应交易日，美股末根为 2026-10-30；原始结果未随仓库保存，不把这次探测当作可复算的最终数据快照。

320 根仅证明当前连接能返回超过完整温度分数理论最小的 294 根有效日 K。仍须核对复权、缺失、四 ETF 同日对齐、SOXX 拆分与显示期前预热；终端的服务端 Longbridge 会话也须独立实测。

| 对象或来源 | 本轮现象 | 尚未满足的门槛 |
| --- | --- | --- |
| 香港 `HSI.HK` | 当前连接请求 70 根日 K，返回 70 根 | 服务端会话、许可、其他香港指数与长期历史仍待核 |
| 新加坡 `STI.SG` | Longbridge 返回 `no quote access`（错误码 301604） | 当前账户权限不够；须核验可用于自动更新与展示的替代来源，不能以空卡验收 |
| `DIA.US` 估值历史 | 连接器返回约 59 个按月的 PE 点与当前 PE 字段，首个点显著异常 | 指数／基金口径、异常点、时点、官方交叉核对及使用许可均未通过；不得据此计算道指 PE 分位 |
| 其他八对象估值历史 | 部分指数返回空或无效；`QQQ.US` 返回 PB 而非预设 PE | 每个对象的主估值定义、同口径历史和展示权利须另找并验证 |

2026-11-01 再次顺序调用 `valuation_history`：四个 A 股指数（`000688.SH`、`399006.SZ`、`000300.SH`、`000922.SH`）均无当前估值与历史列表，`QQQ.US` 同样无有效 PE 序列。`SOXX.US` 返回标作 PE 的当前 `1.4x` 和 59 个月度点；`SPY.US` 返回标作 PE 的 `6.73x` 和 59 点；`DIA.US` 为 `21.27x` 和 59 点，首点 `3.46x`。这些数值及 ETF 与指数口径尚未通过发行方或指数官方交叉核对，尤其 SOXX／SPY 的低倍数不能直接作为可用 PE 展示或计算分位。连接器读取成功不代表估值门槛通过。

发行方对照进一步证实长桥这些“PE”不可直接使用：[State Street SPY 官方页](https://www.ssga.com/us/en/intermediary/etfs/state-street-spdr-sp-500-etf-trust-spy)所列标普指数 Price/Earnings 为 `24.48x`（2026-10-28），明显不同于连接器 `6.73x`（2026-10-30），两者日期／基金与指数口径亦不同；[iShares SOXX 官方页](https://www.ishares.com/us/products/239705/SOX)列基金 P/E `64.88x`（2026-09-09），明显不同于连接器 `1.4x`（2026-10-30）；[Invesco QQQ 官方页](https://www.invesco.com/us/en/financial-products/etfs/invesco-qqq-trust-series-1.html)有基金当前 P/E 与前瞻 P/E，但无已核实的自动历史序列。这些官方值是交叉核验线索，不因不同日期直接判定哪一方绝对错误；结论是当前连接器序列**不能被标为与官方同口径 PE**。

同日用 AKShare 连接器的 `stock_zh_index_value_csindex` 试读中证指数数据：`000688`、`000300`、`000922` 各返回最近 20 行，最新为 2026-10-30，并带“市盈率1／2、股息率1／2”；`399006` 不属该中证接口，未返回表。 [国证指数官网](https://www.cnindex.com.cn/index.html)公开列有创业板指的当前静态／滚动 PE。此处只证明近期数值存在，**没有**验证“市盈率1／2”及“股息率1／2”的官方定义、3／5／10 年历史、服务端可读与再展示许可，不能据 20 行计算长期分位。下一步优先核中证与国证的官方历史下载／接口说明及授权，分别选择同口径主指标。

[AKShare 官方接口文档](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)明确说明中证估值接口“只能返回近期的数据”，并定义“市盈率1／股息率1”为总股本口径、“市盈率2／股息率2”为计算用股本口径。因此该接口可作近期数值候选，**不能单独满足 3／5／10 年历史分位**。[理杏仁大陆指数基本面 API](https://www.lixinger.com/api/open-api/html-doc/cn/index/fundamental)文档列有 PE-TTM、PB、股息率历史及 3／5／10 年分位字段，需用户专属 Token；尚未取得账号、实测返回或核实 API 权利及计费，故仅列候选。第三方网页即使已显示各指数分位，也不能替代可授权、可复算的数据来源。

按用户 2026-11-01 决定，暂不新开理杏仁账号，继续找无需新增账号的通路。AKShare 的乐咕乐股 `stock_index_pe_lg` 对“沪深300”返回 259 个约月频点（2005-04-29 至 2026-10-30），含滚动 PE；“创业板指”“科创50”“中证红利”均报不支持的 `KeyError`。它对沪深300虽有足够长的理论样本，仍须核来源条款、更新稳定性及其口径与中证官方值差异，不能横接官方日度序列。今日投资数据市场的[指数估值 API](https://std.investoday.net/apidocs/api-reference/%E6%8C%87%E6%95%B0%E4%BC%B0%E5%80%BC%E4%BF%A1%E6%81%AF/%E6%8C%87%E6%95%B0%E4%BC%B0%E5%80%BC%E4%BF%A1%E6%81%AF)文档包含历史日期和 5 年分位，但明确要求 API Key 与 L2 资源包，尚非免账号路径。[第三方指数估值看板](https://etf.whatsid.me/indices/valuation)已显示四对象的分位，然而未核实其原始序列、自动接口或再展示许可，不能直接复制数值或曲线。

补查美国长期估值：[Robert Shiller 官方数据页](https://shillerdata.com/)公开提供自 1871 年起的月度价格、盈利及 CAPE 工作簿，并说明盈利数据的月度插值方法。这是**标普长期 CAPE 的候选来源**，不是 SPY 当前滚动 PE、未来一年 PE 或其他七对象的现成历史；尚未实测文件最新月份、服务端更新、下载稳定性和再展示权利，不能将 CAPE 与当前 PE 拼成同一分位。S&P 官方历史指数服务的完整数据需机构订阅，亦非全八对象的免账号解决方案。

NSE Indices 的[历史报告](https://niftyindices.com/reports)有 NIFTY 50 下载界面，但其[使用条款](https://www.niftyindices.com/terms-of-use)禁止未经书面同意的系统性自动采集；因此网页可下载不构成终端自动刷新授权。官方另列有[数据订阅途径](https://www.niftyindices.com/offerings/data-subscription)。SGX 有 [STI 指数页面](https://www.sgx.com/indices/products/sti)，但仅能看到网页信息，尚未证明本项目可自动取历史并再展示。

### 2026-11-01 东财 STI 候选实测

[东财 STI 行情页](https://quote.eastmoney.com/gb/zsSTI.html)在本地请求返回 HTTP 200；[AKShare 源码](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_settlement_price_sgx.py)使用东财 `100.STI` 代码请求历史日 K，说明存在可测试的技术线索。但同一台本地服务器请求东财 `push2his` 日线和 `push2` 报价接口均以 `ResponseEnded` 提前断开；带页面 Referer、常见 User-Agent、网页公共参数重试仍相同。因此当前**未拿到任何可核验的 STI 报价或历史行**，不能把东财列为已接通来源。东财页面可访问不等于非公开数据接口稳定或允许本项目再展示。另未核实到东财的 NIFTY 50 指数代码；名称相近的 `NFTY` ETF 不得冒充指数。

### 2026-11-01 同源全球指数 API 候选

[Twelve Data 官方指数目录](https://twelvedata.com/indices)同时列出 STI Index 和 Nifty 50，宣称提供实时及历史 API。当前电脑对其 `time_series` 演示请求可连接，但无正式密钥返回 HTTP 401；因此**没有实测到历史行、更新时间或真实账户权限**。[官方套餐说明](https://twelvedata.com/pricing)区分测试、内部展示与程序化处理权限；本终端要计算 1／5／20 日变化、缓存和显示，须在试用或采购前核对允许的具体套餐与指数授权，不能仅凭目录页面选定。另一提供商 Infoway 也分别列有 [STI](https://infoway.io/en/stock-api/sti) 与 [NIFTY](https://infoway.io/en/stock-api/nifty) API 页面，但尚未核验数据来源、许可、实际返回和供应商稳定性，暂作备选。不会在未核验前购买或输入密钥；取得账号后只在服务端配置凭据。

进一步核对 [Twelve Data 个人套餐与用途说明](https://twelvedata.com/pricing)：免费 Basic 只准测试，不准向用户展示；Grow 可内部展示，但页面明确限制程序化处理、存储和转换；Ultra 才明确允许内部计算、存储与展示，标价从每月 999 美元起。具体指数是否包含在某套餐、及本项目许可仍须供应商确认。因此不应仅为这两个市场直接引入订阅。供应商的[个人与商业用途说明](https://support.twelvedata.com/en/articles/5332349-commercial-and-personal-usage)也区分个人内部使用与对第三方展示。

### 2026-11-01 长桥可读的市场 ETF 替代线索

当前 Longbridge 连接分别请求 `EWS.US`（新加坡股票 ETF）与 `INDA.US`（印度股票 ETF）100 根日线，均返回 100 根，覆盖 2026-06-10 至 2026-10-30，末根有非零成交额。两只基金**不是** STI 或 NIFTY 50：持仓篮子、费用、美元汇率、交易时区和美股收盘日均可能导致数值与当地指数不同。2026-11-01 用户同意将它们作为清楚标注的“新加坡／印度市场 ETF 代理”纳入 V1.5 亚太观察与轮动池；显示美股交易日、美元价格和代理口径，不更名冒充指数。100 根已超过 1／5／20 与 60 日轮动比较的理论最小窗口，但尚未核对终端服务端会话、复权、持仓覆盖及展示许可，故不算完成数据接入。

[iShares EWS 官方基金页](https://www.ishares.com/us/products/239678/ishares-msci-singapore-etf)说明其跟踪新加坡股票篮子；[iShares INDA 官方基金页](https://www.ishares.com/us/products/239659/ishares-msci-india-etf)列出 MSCI India Index (Net) 为基准。这进一步确认它们不采用 STI／NIFTY 50 口径；页面说明应分别写成“新加坡股票 ETF”与“印度股票 ETF”，并注明基金价格收益及汇率影响。

## 下一步核验顺序

1. 为八个温度对象取可归档的服务端原始响应，核对至少 294 根有效日 K、展示期预热和同日对齐；复算旧 A 股数值和新对象向量。
2. 建立八个估值对象的来源矩阵。道指先核同口径历史 PE；无合格序列时验证 State Street DIA 过去 365 日分配额与同日 NAV 的历史基金分配收益率，单独命名和展示。
3. 核 `EWS.US`／`INDA.US` 的服务端会话、展示权利、复权和持续更新；分别显示美股交易日。其余亚太核心指数还须核数据源、当地收盘日及 1／5／20 日窗口。STI／NIFTY 50 直连仍是后续备选，不作为本版门槛。
4. 核轮动 60 日历史、汇率与 ETF 收益口径，再制定六判断的独立证据和预警阈值；只有来源、历史、许可、算法四项均通过，才进入相应产品编码。
