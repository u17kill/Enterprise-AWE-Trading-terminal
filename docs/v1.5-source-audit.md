# V1.5 数据来源核验记录

日期：2026-11-01。阶段：开发前数据门槛核验；以下是连接器读取结果，**不是终端服务端已接入或可再展示的证明**。

## 本轮实测

使用当前 Longbridge 连接的日线读取，要求 320 根已收盘常规时段日 K，并仅统计根数、首尾时间和非零成交额。A 股 `000688.SH`、`399006.SZ`、`000300.SH`、`000922.SH` 与美股 `QQQ.US`、`SOXX.US`、`SPY.US`、`DIA.US` 各返回 320 根，成交额字段均非零。A 股末根为 2026-10-29 对应交易日，美股末根为 2026-10-30；原始结果未随仓库保存，不把这次探测当作可复算的最终数据快照。

320 根仅证明当前连接能返回超过完整温度分数理论最小的 294 根有效日 K。仍须核对复权、缺失、四 ETF 同日对齐、SOXX 拆分与显示期前预热；终端的服务端 Longbridge 会话也须独立实测。

NSE Indices 的[历史报告](https://niftyindices.com/reports)有 NIFTY 50 下载界面，但其[使用条款](https://www.niftyindices.com/terms-of-use)禁止未经书面同意的系统性自动采集；因此网页可下载不构成终端自动刷新授权。官方另列有[数据订阅途径](https://www.niftyindices.com/offerings/data-subscription)。SGX 有 [STI 指数页面](https://www.sgx.com/indices/products/sti)，但仅能看到网页信息，尚未证明本项目可自动取历史并再展示。

### 2026-11-01 东财 STI 候选实测

[东财 STI 行情页](https://quote.eastmoney.com/gb/zsSTI.html)在本地请求返回 HTTP 200；[AKShare 源码](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_settlement_price_sgx.py)使用东财 `100.STI` 代码请求历史日 K，说明存在可测试的技术线索。但同一台本地服务器请求东财 `push2his` 日线和 `push2` 报价接口均以 `ResponseEnded` 提前断开；带页面 Referer、常见 User-Agent、网页公共参数重试仍相同。因此当前**未拿到任何可核验的 STI 报价或历史行**，不能把东财列为已接通来源。东财页面可访问不等于非公开数据接口稳定或允许本项目再展示。另未核实到东财的 NIFTY 50 指数代码；名称相近的 `NFTY` ETF 不得冒充指数。

### 2026-11-01 同源全球指数 API 候选

[Twelve Data 官方指数目录](https://twelvedata.com/indices)同时列出 STI Index 和 Nifty 50，宣称提供实时及历史 API。当前电脑对其 `time_series` 演示请求可连接，但无正式密钥返回 HTTP 401；因此**没有实测到历史行、更新时间或真实账户权限**。[官方套餐说明](https://twelvedata.com/pricing)区分测试、内部展示与程序化处理权限；本终端要计算 1／5／20 日变化、缓存和显示，须在试用或采购前核对允许的具体套餐与指数授权，不能仅凭目录页面选定。另一提供商 Infoway 也分别列有 [STI](https://infoway.io/en/stock-api/sti) 与 [NIFTY](https://infoway.io/en/stock-api/nifty) API 页面，但尚未核验数据来源、许可、实际返回和供应商稳定性，暂作备选。不会在未核验前购买或输入密钥；取得账号后只在服务端配置凭据。

## 下一步核验顺序

1. 为八个温度对象取可归档的服务端原始响应，核对至少 294 根有效日 K、展示期预热和同日对齐；复算旧 A 股数值和新对象向量。
2. 建立八个估值对象的来源矩阵。道指先核同口径历史 PE；无合格序列时验证 State Street DIA 过去 365 日分配额与同日 NAV 的历史基金分配收益率，单独命名和展示。
3. 找到 STI、NIFTY 50 及其余亚太核心指数可持续自动获取、可在本项目展示的来源，再核本地收盘日及 1／5／20 日窗口。
4. 核轮动 60 日历史、汇率与 ETF 收益口径，再制定六判断的独立证据和预警阈值；只有来源、历史、许可、算法四项均通过，才进入相应产品编码。

关键来源无法通过时，按[需求方案](superpowers/specs/2026-11-01-v15-canary-redesign-design.md)与用户重议验收口径。当前未修改产品代码。
