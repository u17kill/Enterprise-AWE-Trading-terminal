# V1.3 Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver the three V1.3 surfaces with honest, dated data and private portfolio editing.

**Architecture:** Extend the existing Next.js terminal. Market data is requested only by the existing refresh action through server routes; private positions and notes stay in browser storage. Each data source has an explicit adapter and absence state.

**Tech Stack:** Next.js 16, React 19, TypeScript, Vitest, Lightweight Charts.

**Spec:** `docs/superpowers/specs/2026-10-24-v13-terminal.md`

## Global Constraints

- Do not commit individual position data or credentials.
- Do not substitute ETF prices for spot, yields, or indexes.
- Keep manual refresh and show source timestamps.

## Review Focus

- Missing or unauthorized quote -> explicit unavailable state, no sample value.
- Negative or absent EPS -> no misleading PE.
- Stale financial reports -> visible report period.
- Old portfolio import -> preview, no automatic save.
- Mixed currencies -> totals grouped by currency.

## Implementation ledger

Ruling: Consolidate the four component commits into one V1.3 review commit — the shared refresh API and UI surfaces changed together, so a single verified tree is easier to review — the cost is less granular history if a feature is later reverted.
Ruling: Keep Nikkei 225, KOSPI, gold history and unverified forward/index PE explicitly unavailable — no direct, consistent data source was established — the cost is that these requested values remain pending.
