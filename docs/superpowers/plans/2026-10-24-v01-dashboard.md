# V0.1 Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a runnable light-theme dashboard with curated symbol search, persistent favorites, and a chart workspace.

**Architecture:** Next.js App Router serves two routes. Client state handles favorites via a small storage module; a shared catalog supplies symbol metadata and labeled sample trend data. A server-side route can be added later for market data.

**Tech Stack:** Next.js, React, TypeScript, CSS, Vitest/Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-24-v01-dashboard-design.md`

## Global Constraints
- All sample values must be visibly identified as examples, never current quotes.
- No market data credentials in client code or committed files.
- Desktop dashboard has four columns; smaller screens reflow.

## Review Focus
- Corrupt or stale browser storage falls back safely.
- Duplicate additions do not repeat a card.
- Search finds English symbols and Chinese names.
- Removing a card persists after refresh.
- Unknown chart symbols return a not-found view.
