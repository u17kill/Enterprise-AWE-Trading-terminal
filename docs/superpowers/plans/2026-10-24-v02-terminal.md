# AWE Trading Terminal V0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add manual market refresh, selectable indicators and direct deletion of individual drawings to the V0.1 dashboard and chart workspace.

**Architecture:** Keep indicator mathematics as pure functions. Serve market data through a server-only Longbridge adapter and small route handlers; the browser never receives credentials. The chart uses independent indicator panes below the candlesticks. If a provider or entitlement is unavailable, retain clearly labeled sample data and show an actionable refresh error.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Lightweight Charts 5, Vitest, Longbridge OpenAPI Node SDK.

**Spec:** [V0.2 GitHub requirement baseline](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/issues/2)

## Global Constraints

- Manual refresh only: no polling or streaming.
- MA choices: 5, 10, 20, 200, 250; several may coexist.
- MACD, RSI, S&P 500 breadth above SMA50 and SMA200 are independently optional.
- All provider credentials remain server-only; sample and live data must be visibly distinguished.
- Existing drawings and browser-local persistence must continue to work.

## Review Focus

- Missing credentials or denied market permissions must show a clear error without inventing a fresh quote.
- Unsupported catalog symbols must not be silently mapped to unrelated securities.
- Indicator warm-up periods must not produce misleading zeroes.
- Drawing deletion must target the selected item and persist after reload.
- Breadth must never be computed from a partial constituent set while labeled as the full S&P 500.
