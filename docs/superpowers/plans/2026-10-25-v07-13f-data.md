# V0.7 13F 已公开持仓 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 首屏展示 29 家机构最近一次已公开的 13F 持仓，并让手动更新核对新申报。

**Architecture:** 将 13f.info 的公开转录表作为当前环境的备用传输来源，全部结果保留 SEC 原件、季度和提交日。提交一份可离线显示的 29 家快照；服务端只在手动更新时核对目录，申报未变则沿用快照，单家失败保留旧数据。客户端在本地保存最近一次成功结果。

**Tech Stack:** Next.js 16、React 19、TypeScript、Vitest、Node 24、13f.info 公开页面与数据接口。

**Spec:** `docs/superpowers/specs/2026-10-25-v07-leader-holdings-design.md`

## Global Constraints

- 13F 具有季度延迟且不包含股票空头；用户要求至少显示已有申报。
- 显示季度末、提交日、转录来源和 SEC 原件；不能把转录写成 SEC 直连。
- 潘兴广场 13F-NT 要沿其列出的母公司申报，Citadel 修正申报要明确标记，查诺斯与 Scion 要显著标旧季度。
- 当前 SEC 直连返回 403；备用来源的失败不能清空上次成功快照。

## Review Focus

- 29 家都有申报快照，不能默默以空值充数。
- 同一机构最新表为 13F-NT、RESTATEMENT 或未来出现追加修正时，来源与解释正确。
- 证券的千美元单位与百分比分母明确；期权不当作普通正股。
- 单家来源失败时仍显示其他 28 家及该家的旧季度。
- 搜索、切换分组和离开页面后仍可查看已保存的最近成功数据。
