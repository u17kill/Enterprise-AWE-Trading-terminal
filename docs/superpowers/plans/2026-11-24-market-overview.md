# 市场总览重构实施计划

基于用户提供的施工图 docs/market-overview-requirements.md，直接进入开发；既有 Next.js、React、蓝白主题继续使用。

1. 将参考项目的市场取数引擎纳入仓库，保留分品种批次、收益率 bp、交易日期、分时抽稀逻辑。添加 JSON bridge，把写入目录定向到本机持久目录；不修改参考项目与持仓原件。
2. 增加 /api/market、config、refresh、search、brief 路由；子进程参数独立传递；刷新与配置修改互斥。原子保存，缺卡刷新失败保留旧缓存。
3. 首页改为今日市场 / 指数与大类资产 / 自选股三段。支持筛选、搜索、增删、可见槽位拖动、批量导入、板块拖动和独立持仓镜像。
4. 验证取数、缓存、排序、单位、代码映射；执行类型检查、相关测试及生产构建；更新状态文档和 PR。

实施决定：窄屏在 620px 改两列、360px 一列，矩阵只在自身容器横向滚动。展示参考默认配置，用户配置只在首次缺失时初始化。原总览的五灯模块已在其他指标页存在，本页按施工图三段职责重构。
