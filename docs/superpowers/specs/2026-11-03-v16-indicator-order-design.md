# V1.6 指标大全卡片排序需求草案

日期：2026-11-03。状态：页面范围与单机保存范围已确认；首版开发完成，待用户验收。交付与验证见 [V1.6 状态](../../v1.6-status.md)。

## 用户提出的需求

仅在“金丝雀指标 → 指标大全”页面，同一个类别下面的指标卡片可以拖拽移动，让用户自由决定该类别中的展示位置。市场温度、估值分析和短线精灵暂不增加排序功能。

用户最终确认 V1.6 只考虑一台电脑；多台电脑同步留待后续迭代。自定义顺序在这台电脑上刷新、离开再返回、重新打开应用后保留。现有持仓地图采用本机文件保存并可跨本地预览端口读取，可作为排序保存范围的参考。V1.6 不引入产品账户或跨设备同步服务。

当前指标大全有三个类别：宏观先行、美股风险、A 股资金与情绪。卡片顺序由固定指标列表决定，刷新页面后仍按默认顺序显示。

## 待确认的交互建议

- 仅允许在同一类别中调整顺序；跨类别移动会改变指标归属，暂不作为本需求的一部分。
- 拖动时明确显示目标位置，松开后立即排列；数据更新或展开指标说明不改变顺序。
- 自定义顺序在同一台电脑上刷新、离开再返回及重新打开应用后保留。保存失败时提示，避免把未保存的顺序误标为成功。
- “预留指标”占位卡固定在类别末尾；以后加入新指标时，先放在已有卡片后、占位卡前。
- 为不便使用鼠标拖动的用户提供同类卡片“上移／下移”操作，并考虑恢复默认顺序的入口。具体控件形式待 UI 确认。

## 验收口径草案

1. 三个类别各自可排序，移动一个类别的卡片不影响另外两个类别。
2. 重新加载页面后，自定义顺序保留；刷新指标数据不重置顺序，也不改变数值、日期、来源或说明。
3. 占位卡保持在最后；以后新增指标能够以合理默认位置出现。
4. 鼠标和键盘都能完成排序，窄屏页面可正常操作。
5. 同一台电脑的本地预览重建或端口变化后仍能读到已保存的顺序；多台电脑同步不计入本期验收。

本文件保留原始需求和设计建议；实际交付与验证以 V1.6 状态记录为准。

## 首版实现决定

- 指标顺序只保存每类指标 ID，与行情读数分离。现有目录增加新指标时，旧排序仍有效，新指标接在已保存指标之后；移除的旧指标 ID 自动忽略。
- 使用本机服务端文件保存，沿用持仓地图同级的数据目录；接口仅供 `localhost` 或 `127.0.0.1` 的同源页面使用。跨电脑同步不在本期范围。
- 每张卡片上方提供拖动手柄和上下移动按钮；拖动目标以蓝色边线提示。拖动采用指针事件，支持窄屏触控操作；卡片本身仍可展开阅读说明。
- 每类提供恢复默认顺序。保存期间暂停重复移动；保存失败时还原上次顺序并显示错误。
- 用户尚未验收；以上实现不能作为数据来源或行情指标已核验的证明。
