# V1.6 指标大全卡片排序需求草案

日期：2026-11-03。状态：需求讨论中，尚未开发或验收。

## 用户提出的需求

在“金丝雀指标 → 指标大全”页面，同一个类别下面的指标卡片可以拖拽移动，让用户自由决定该类别中的展示位置。

当前指标大全有三个类别：宏观先行、美股风险、A 股资金与情绪。卡片顺序由固定指标列表决定，刷新页面后仍按默认顺序显示。

## 待确认的交互建议

- 仅允许在同一类别中调整顺序；跨类别移动会改变指标归属，暂不作为本需求的一部分。
- 拖动时明确显示目标位置，松开后立即排列；数据更新或展开指标说明不改变顺序。
- 自定义顺序在刷新、离开再返回及重新打开应用后保留。存储范围需结合用户已有的跨本地端口持仓保存体验确定。
- “预留指标”占位卡固定在类别末尾；以后加入新指标时，先放在已有卡片后、占位卡前。
- 为不便使用鼠标拖动的用户提供同类卡片“上移／下移”操作，并考虑恢复默认顺序的入口。具体控件形式待 UI 确认。

## 验收口径草案

1. 三个类别各自可排序，移动一个类别的卡片不影响另外两个类别。
2. 重新加载页面后，自定义顺序保留；刷新指标数据不重置顺序，也不改变数值、日期、来源或说明。
3. 占位卡保持在最后；以后新增指标能够以合理默认位置出现。
4. 鼠标和键盘都能完成排序，窄屏页面可正常操作。

本文件只记录下一迭代需求和待确认建议，不表示排序功能已经交付。
