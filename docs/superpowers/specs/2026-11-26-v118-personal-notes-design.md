# V1.18 个人笔记设计

2026-11-26。依据用户提供的 `D:/projects/deepseek-trading-terminal/docs/需求文档-个人笔记模块.md`。用户已确认：入口位于“投资工具”下；笔记正文与备份只存本机，GitHub仅保存代码、需求与示例。本文为实施前设计，待核对后进入开发；未宣称功能已交付。

## 1. 目标与已确认范围

一个私人纯文本看板：横排主题泳道，纵排笔记卡片，点击右侧抽屉编辑，输入自动保存；首先保证原文不丢失、不被重写、不被后续代码更新覆盖。

包含：泳道增删改名、按钮和拖拽排序；卡片增删改、列内排序、跨列拖动与下拉移动；搜索标题/正文、命中高亮、全量/匹配计数；自动保存、显式状态、手动重试、重读文件、JSON导出、写前备份；多页版本冲突、串行写回、正确本地时间、即时字数、键盘可达。

不含：多看板、Markdown/富文本、附件、标签、提醒、AI改写、自动摘要、页面历史恢复、导入JSON、云账号和多设备同步；本期也不做离线安装版或file://导出编辑器。服务已经打开的页面在服务短暂中断时可继续保留草稿；服务完全停止后重新打开网址不保证可用。笔记不会被市场抓取或AI任务读取/改写。

## 2. 实现路线与取舍

采用现有Next站内原生页面与服务端文件保存，沿用基金宪法中已验证的版本校验、跨进程排他锁、写前备份、原子替换思路。用户已认可原生集成、同站风格和本机私有存储方向。

对照路线：仅浏览器存储无法满足源码外权威文件和可恢复性；嵌入DeepSeek整页会带入另一套导航/样式、分钟时间比较和并发覆盖缺口，并依赖D盘工程；两者不采用。具体组件拆分、拖拽实现交由实施者决定，避免无关全站重构。

## 3. 入口和页面布局

路径 `/notes`。左侧“投资工具”依次为图表空间、当前持仓、期权计算、个人笔记；共用的投资工具横向切换栏也同步新增个人笔记，现有三页导航一致。

沿用现有ToolsPageHeading与ToolsPageNav：页面主标题“个人笔记”，简短说明“按主题收纳想法，原文自动保存在本机”，右侧“导出JSON”。不重新加此前取消的“工作台 / 投资工具 / 基金宪法”整条顶栏。

标题后为共用工具切换栏，再是紧凑工具条：泳道数、卡片数、正文字数、搜索匹配数；搜索框带清除、重读文件、保存状态，失败时出现重试。状态始终可见；详细错误/冲突另起提示条。

下方泳道横排，每条约300px、细边框浅蓝灰列底、白色卡片；列头显示拖动柄、可改名列名、数量、左右移位、删除。列底“新建卡片”；看板末尾“新建泳道”。首版初始给“随手记 / 待处理 / 已归档”三条空泳道，列名均可改，不强制用户读示例。此初始空泳道决定由实现者提出，不导入参考项目内可能存在的私人笔记；可在未保存首次状态说明“尚无笔记”。用户清空到0条后不得重新补回三列。

横向溢出只发生在看板内部；标题、工具条、页面不整体横向滚动。列内滚动高度随浏览器视口变化，不用大片固定空白。手机单列约视口宽，抽屉满屏。无行情语义红绿卡色，删除使用文字提示。字体与现站保持一致。

抽屉约520px，顺序：标题、纯文本正文（最小260px）、所属泳道、创建/修改时间；底部删除、正文字数、关闭。打开自动聚焦标题；Esc或Ctrl/Cmd+Enter关闭，焦点回卡片；遮罩阻止背后拖动，Tab约束在抽屉，不因重绘跳光标或重置滚动。关闭只收起界面，不撤销输入。

卡片预览正文最多140字符且两行；标题空显示“（无标题）”；正文和标题均空允许保存。正文细节保留连续空格、换行、缩进和标记文本，绝不trim/自动格式化。全文只在抽屉显示。

## 4. 搜索和排序规则

搜索标题与正文子串，大小写不敏感，不查泳道名与时间，不做正则/模糊。保留全部泳道，列头显示匹配/总数；无匹配列显示对应空状态。工具条搜索开启即显示匹配数，包括0，避免空白猜测。清除立即恢复。

正文140字符预览之外的命中也要在卡片明确标出“正文包含匹配”，避免卡片出现却看不到高亮原因；抽屉保留原文，不能为高亮改写输入内容。

无筛选时支持列/卡片拖拽插入和相邻按钮换序，边界按钮禁用。搜索时暂禁卡片拖拽/排序并解释“清空搜索后调整顺序”，避免过滤顺序与实际数组顺序歧义；抽屉下拉仍可跨列移动。触屏/键盘有按钮和下拉兜底。卡片可聚焦、Enter/Space打开；拖动柄与打开动作分离。

删除卡片、删除整泳道均确认，删除列提示其中卡数。删除不承诺撤销，依靠写前备份；操作和显示不阻塞自动保存。

## 5. 数据契约和时间

单份notes.json，结构沿用参考：schemaVersion=1、updated、columns数组；每列id/title/cards；每卡id/title/body/created/updated。列id使用col-前缀，卡c-前缀，全部ID全局唯一，稳定不从标题生成。顺序就是数组顺序。用户正文外的未知字段在读写往返保留，以免以后扩展被旧代码悄悄删除；派生stats/errors/warnings不成为正文的一部分。

服务端快照另含revision（文件内容哈希，缺失为missing）、updatedAt、stats、warnings与ok。没有源文件时只返回三空列，不写入；已有合法0列文件保持0列。坏结构、重复ID、错误字段类型拒写，原文件保持；损坏源文件不能退回默认稿并自动覆盖。

标题>60字符、列名>16字符仅提示，照存原文，不截断；安全体积上限2MiB，超限显式失败并可导出，不静默裁切。实现可使用最多100列/5000卡的防滥用界限，必须显式提示，不改变目标200卡/5万字范围。

字数统一为正文字符串UTF-16长度（与JS body.length一致），包含空白换行标点，不含标题；服务器同算法，emoji以JS计数一致为准。工具栏、抽屉与列计数输入时立即更新，成功回应不能把新一轮输入的统计倒回旧数。

新卡时间以ISO8601保存；文件updated由服务端生成。卡片内容或位置改变更新修改时间，创建时间不改变。展示统一转换本地时区Asia/Singapore，不直接截ISO当本地时间。兼容旧YYYY-MM-DD HH:MM按UTC+8解释，不重写旧正文。服务端不接受客户端伪造文件级updated；卡片有效原时间可保留，修改时间由保存批次核对生成，不能把没改的所有卡都标为更新。

本机默认源码外目录 `C:/Users/T14s/Documents/Codex/.awe-terminal-data/notes.json`，支持AWE_NOTES_DATA_DIR及现有本机数据根配置。笔记备份放同根notes-backups目录、滚动40份，不与持仓/宪法备份混清。部署重建不改变数据根，不读取参考工程为持续依赖。

## 7. 自动保存状态机

每次内容改动先同步尝试保留浏览器草稿，再等待600ms停止输入后写文件。同一页只允许一个保存请求在途：请求捕获不可变快照与本地变更序号；写入期间新输入只标记pending，成功后用新revision继续保存最新快照。旧响应不得替换新正文、清掉更新的草稿或显示“全部保存”。服务端跨请求/跨进程也排他。

浏览器每页独立草稿，记录数据、基准revision、变更序号和保存时间；复制标签页要分叉写入键，刷新可恢复本页上一份，其他页或历史副本手动选择。恢复时比较revision，不用分钟时间“谁新听谁的”：源文件版本没变才可自动续存；不同版本进入冲突，暂停自动覆盖。

七个基础状态：已写入源文件（时间）、已恢复草稿待写回、有改动准备写回、正在写回、未连本地服务改动留在草稿、写回失败草稿保留、草稿也未写成仅当前页；另有明确冲突/源文件读取失败。文件未实际写入时不能显示已保存。浏览器草稿失败不掩盖文件保存是否成功，失败文案随实际保障更新。

失败不清草稿、不丢焦点、不禁止继续写字。可手动重试，避免无限快速重试；网络恢复先核对版本再续存，不盲写。离页/刷新若草稿也失败，明确提醒可导出。关闭抽屉不影响队列。

首次读取尚未完成时不开放自动保存，避免用默认空板覆盖真实文件。首屏采用请求时读取的服务端快照，随后核对；既有源文件错误单独呈现。Next构建不把私人正文打进静态产物，也不因为运行机个人文件坏掉而破坏其他模块构建；用种子/结构测试替代参考项目的静态HTML注入要求。

## 8. 重读文件和冲突

“重读文件”是手动选择权威文件的出口：先暂停自动写、等当前在途写结束，再取最新文件；有待保存改动必须确认并保留恢复副本/提供导出。读成功才切换页面并清理本页草稿，失败原草稿不删，文件不改。切换操作期间的新输入要么暂时锁定并说明，要么捕获独立版本，不能被迟来的GET盖掉；实施采用短暂禁用输入直到读完。

两页保存版本不符返回409，保留本页与源文件两份，显示可选“使用文件”“保留本页覆盖”。选择文件先备份/保留当前稿；选择覆盖先取最新revision并提示，服务端再校验，发生新冲突仍拒绝。绝不自动合并正文；只有本页确认的快照能被写入。

## 9. API和写入保护

GET /api/notes：no-store，返回当前快照和统计；不存在与读取失败可区分。POST /api/notes：提交notes及revision；返回服务器实际快照、revision、as_of、stats、bytes与备份名。提示只显示相对文件名，不必泄露绝对目录。

顺序：结构/字节/ID校验 → 排他 → 校验文件版本 → 写前逐字节备份并同步 → 唯一临时文件同步 → 原子替换 → 返回成功。备份失败阻止写；备份清理失败不把已完成写入误报失败。死进程锁可恢复，活锁不按年龄抢占。只接受本机同源写，正确处理Next localhost规范化与真实Host。400非法、403来源、409冲突、413体积、429忙、500损坏、503存储不可用。
