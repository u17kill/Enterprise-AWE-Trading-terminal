# V1.14 资产风向：确认方案

用户提供的资产方向施工图作为功能与数据基线（docs/asset-direction-requirements.md），入口调整为现有金丝雀指标下的“资产风向”，不复制参考项目的顶级页签体系。

七段依次为风险偏好总览、模块×资产矩阵、本地政策利率、14类资产、19项读数、确认层、人工政策判据。复用参考 fetch/score/build 链，统一评分结果与渲染函数，页面及独立 HTML 同源；蓝白主题、紧凑字体、响应式卡片和表格容器滚动。内嵌文档隔离样式，避免污染其它页面。

用户确认：有效指标仅一项的模块整块剔除，不按半权重计入总分或资产分。其它评分权重与弹性保留。矩阵合计说明改为归一化结果，不能声称贡献格直接相加等于资产分；只有灯色实际变化才显示“降”。n 显示为截尾后有效数量。移除参考渲染中写死的“当前”数字和判断。

人工政策和笔记首次从提供的文件导入，此后只从本机持久目录读取；保留原文确认状态并披露导入来源，不宣称已再次核验。自动取数不改人工文件。缺失值保留 null；缺项超过3时保留上一份评分。原始响应、评分与每日快照存于源码之外；单日快照含19项指标。

数据先按施工图指定的 FRED、CBOE、Yahoo、BIS及台湾央行验证；不替换代理口径、不擅自补 T4 宽度、不因本地利率缺失改变分数。手动刷新独立于总览与其它频道，失败保留旧结果。
