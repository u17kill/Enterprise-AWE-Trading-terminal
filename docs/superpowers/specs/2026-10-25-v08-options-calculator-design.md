# V0.8 期权计算模块设计（待确认）

## 目标

在 Enterprise AWE Trading Terminal 左侧新增“期权计算”模块。用户先通过十张策略卡理解常见期权组合的买卖方向、到期盈亏形状与适用情景，再选择一张，用手填的股价、执行价、权利金和合约张数计算到期日的盈亏、盈亏平衡点及风险范围。不接行情或交易账户，也不发出订单。

## 已确认的计算口径

用户选择先计算**同一到期日的到期盈亏**；到期前估值、隐含波动率、希腊值和实时价格暂不做。期权权利金以每股价格输入，默认一张美股标准期权对应 100 股，并可修改合约乘数以适应其他合约。每种策略的期权腿共用合约张数，组合比例按策略固定。备兑看涨另有独立的**股票成本价**输入，持股数 = 合约张数 × 合约乘数；当前股价只作图上定位。盈亏为扣除/加入初始净权利金后的美元结果；V0.8 暂不计手续费、税、滑点、保证金、提前行权和股息。除备兑看涨的股票成本价外，当前股价不会改变到期盈亏平衡点。

## 十种首批策略（建议清单）

| 分类 | 策略 | 固定组合方向 | 图形要表达的核心 |
| --- | --- | --- | --- |
| 看涨 | 买入看涨 Long Call | 买入 1 Call | 有限损失、上涨收益继续增加 |
| 看跌 | 买入看跌 Long Put | 买入 1 Put | 下跌获益、权利金为最大损失 |
| 持股增收 | 备兑看涨 Covered Call | 每张期权持有与合约乘数相同股数 + 卖出 1 Call | 收取权利金、上涨收益被封顶 |
| 择价买入 | 现金担保卖出看跌 Cash-Secured Put | 卖出 1 Put，另备行权资金 | 收取权利金、下跌可能亏损 |
| 看涨价差 | 牛市看涨价差 Bull Call Spread | 买低执行价 Call、卖高执行价 Call | 有限收益与损失 |
| 看跌价差 | 熊市看涨价差 Bear Call Spread | 卖低执行价 Call、买高执行价 Call | 股价不涨过短腿执行价时获益 |
| 看涨价差 | 牛市看跌价差 Bull Put Spread | 卖高执行价 Put、买低执行价 Put | 收权利金，限制下跌风险 |
| 看跌价差 | 熊市看跌价差 Bear Put Spread | 买高执行价 Put、卖低执行价 Put | 下跌获益，收益与损失封顶 |
| 大波动 | 买入跨式 Long Straddle | 同执行价买入 Call 与 Put | 大幅上/下波动才越过两个平衡点 |
| 大波动 | 买入宽跨式 Long Strangle | 买入较低执行价 Put 与较高执行价 Call | 两侧需更大波动；初始成本通常较低 |

用户举例的“买 Put、卖 Call”并非熊市看涨价差的组成。熊市看涨价差的两腿都是 Call，且短腿执行价较低；“买 Put、卖 Call”若同执行价、同到期日，是合成空头股票一类的组合，暂未列入十种。页面会用中文名称、英文名称和逐腿 Buy/Sell 标签明确区分，避免误操作。[期权行业委员会的熊市看涨价差说明](https://www.optionseducation.org/strategies/all-strategies/bear-call-spread-credit-call-spread)。完整策略名称与描述参考其[策略目录](https://www.optionseducation.org/strategies/all-strategies-en)，但图形与中文说明由本项目独立制作。

## 页面结构

沿用现有白底、浅蓝色工作台风格，在侧栏加入入口。页面上部说明“到期日情景计算、手动输入、非实时行情”。策略目录用卡片展示中文与英文名、方向标签、1 句话原理、Buy/Sell 组合及**固定示例的小盈亏图**，帮助快速浏览。点击卡片后，下方/右侧打开策略工作区：一侧为更大的动态盈亏图和零盈亏线、当前股价线、执行价及盈亏平衡点；另一侧为简短说明和该策略需要的输入框。桌面两栏，手机上下排列。

示意图和计算图都由同一套到期盈亏函数绘制 SVG，不使用网上截图。固定示意图使用明确标为“示例”的预设值；实际计算图随输入更新。策略介绍保留外部教育来源链接，不复制外站图片或大段文字。

## 计算与校验

- 将每条期权腿表示为 Call/Put、Buy/Sell、执行价、权利金；在候选到期股价 `S ≥ 0` 时，Call 内在价值为 `max(S − K, 0)`，Put 为 `max(K − S, 0)`。买方盈亏为 `内在价值 − 权利金`，卖方取相反数，乘以张数与合约乘数；备兑看涨再加 `S − 股票成本价` 的持股盈亏。
- 按策略约束输入：执行价、股价和备兑股票成本价大于零，权利金非负，张数与乘数为正整数；牛市看涨、熊市看涨、牛市看跌、熊市看跌各自的高低执行价有序；跨式两腿执行价相同，宽跨式 Put 执行价低于 Call。错误输入旁即时说明原因，不输出误导性的数值。若手填权利金让通常的信用价差变成净支出、或借记价差变成净收入，只提示“与常见报价方向不同”，仍按输入如实计算并标示净借记/贷记。
- 从分段线性到期盈亏函数求零点，而不是从图像像素猜。显示一个或两个盈亏平衡点、当前股价假设下的到期盈亏、可计算的最大盈利/最大亏损；无上限时明确显示“理论上无上限”。曲线左端为 `S=0`，右端覆盖当前股价、全部执行价及全部有限盈亏平衡点并留可见边距；在无限收益方向提示“曲线继续”。
- 计算是教育性到期情景，不是期权报价、获利概率或到期前平仓盈亏；看涨/看跌描述不构成投资建议。

## 实现方式与取舍

已向用户说明两种口径：①到期日确定性盈亏，输入少、曲线可直接核验；②到期前模型估值，需要波动率、期限与利率等假设。用户选择①。技术上采用项目现有的 Next.js/React，策略定义和纯计算函数放在独立模块，客户端页面只负责输入和 SVG 绘制；无需新图表包或服务端凭据。固定示意图与动态图共享公式，减少术语、图形和结果互相矛盾的风险。
