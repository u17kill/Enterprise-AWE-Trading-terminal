# V1.9 持仓地图结构图示

日期：2026-11-08。状态：用户提供参考图并要求在现有数字汇总下新增图示。

## 需求与选择

持仓地图顶部现有的普通总额、期权单列，以及按策略、地区、主题的数字列表保持原位、原口径。图示放在三列数字列表下方，地图主体上方。参考图给出了三种互补的表达：按地区的环形占比图、按策略的分段比例条、按主题的面积方块图。本期采用这三种组合，用现有终端的浅色视觉和策略配色实现；不照搬参考图里的示例金额。

考虑过统一三张饼图，优点是实现简单，但难以阅读十多个主题；也考虑过纯条形图，优点是数值易比较，但不能呈现用户提供的方块结构。因此按参考图的三种不同图形交付。

## 数据与交互

- 三图只读取同一次 `calculateMatrixTotals(matrix)` 的 `totalUsd`、`groups`、`regions`、`columns`，不建立第二套金额计算。灰色已持仓与绿色计划加仓中，只有完整 `数字k` 备注计入；黄色观察、蓝色期权、纯文字和不合格式的备注不计入。现有数字汇总、编辑、持久保存、导入导出逻辑不改。
- 地区环形图显示地区金额占普通总额的比例，中心显示合计，旁边按金额降序列金额和百分比。策略比例条显示各策略金额和占比，分段宽度与金额比例一致，颜色跟随策略。主题方块图面积与主题金额成正比，标题和金额／占比可见；很小的方块至少有悬停或辅助阅读标签。主题同名时以“策略 / 主题”区分。
- 地图编辑后图示立即跟随当前矩阵重算；恢复、刷新或导入地图后也显示同一份当前数据。数字列表和三图金额必须一致。若普通总额为 0，三图显示明确空态，不画虚假的 0% 图。
- 大屏地区与策略并排，主题图独占下一行；窄屏依次纵向排列，不产生整个页面的横向溢出。颜色之外同时给出名称、金额与百分比。

## 验收反馈与视觉调整

用户认可三图的结构与计算逻辑，要求更精致的科技金属质感，并指出小主题块里的长名称被截断。图示专用的绿色、蓝色、红色调整为更沉稳的金属色；方块与比例条用分层渐变、柔和高光及内阴影表达材质，数字列表和地图卡片颜色不改。主题图增高，方块文字允许换行且按窄块缩小字号；图下另列完整主题名称、金额和占比，使很小的仓位也能直接阅读，不依赖悬停。

## 验收

1. 三图置于既有数字列表下方，既有数字、格式和口径不变。
2. 三图份额合计约为 100%（展示四舍五入允许 0.1 个百分点误差），地区、策略、主题各自金额合计等于普通总额。
3. 编辑一张符合条件的卡片金额或状态，相关图形和列表同步变化；期权与观察卡不进入图形。
4. 自定义策略、地区、主题均可显示；金额为零的分类不占面积。总额为零时显示空态。
5. 桌面与窄屏可读，页面整体没有横向滚动。

## 边界

图形展示用户填写的美元仓位备注，不是实时市值、盈亏或经核验的真实持仓。地区沿用当前地图的“日韩台印”合并地区；本期不拆国家、不做多币种换算，也不改变蓝色期权的单列口径。
