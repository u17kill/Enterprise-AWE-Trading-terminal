# V1.7 持仓地图汇总与期权状态设计

日期：2026-11-03。状态：用户已确认页面安排、美元口径与本期开发。

## 目标与范围

持仓地图增加第四种卡片状态“期权”，以蓝色显示。地图上方增加普通仓位总额及按策略、地区、主题拆分的汇总；地图内每个主题 × 地区格子显示小计。汇总随本机持仓地图编辑立即变化，沿用当前持久化文件及导入导出格式。

## 已确认的计算口径

- 所有现有仓位备注中的可解析数字视为美元，不换汇，也不声称是实时市值。
- 仅灰色“已持仓”和绿色“计划加仓”进入普通仓位汇总。黄色“观察中”完全不计入；蓝色“期权”单独列出数量与卡片信息，不进入美元合计。
- 仓位备注必须完整符合 `数字k`，如 `1.5k`、`10k`，忽略首尾空白、兼容大写 `K`。允许最多五位小数，以美分为最低精度；`1.5k` 计为 1,500 美元，`1.234k` 计为 1,234 美元。纯文字、空白、`put 115`、区间 `2.7k–5`、没有 `k` 的数字及超过美分精度的输入均不计入。无法解析时原文继续显示。
- 每张卡片在总额中最多计入一次。策略、地区和主题是同一总额的三种拆分视角，不再相互相加。重名主题在汇总中附策略名区分。
- 地区汇总沿用地图现有的“美国、中国、日韩台印、欧洲”等可编辑分组；其中“日韩台印”是合并地区，不能称作单一国家统计。

## 页面安排

顶部汇总区先显示普通持仓总额及参与计算的卡片数，再以并列分组展示“按策略”“按地区”“按主题”的美元小计。蓝色期权在同一区域独立显示数量和标的／备注，不出现期权金额总计。每个有标的的主题 × 地区格子旁显示该格的普通仓位小计；无可计算金额时显示“—”，避免把未填仓位误认为零。窄屏布局也显示同口径小计。

卡片编辑框增加“期权 · 蓝色”选项，图例同步增加蓝色。已有用户数据不自动改状态，尤其不凭 `put` 字样推断期权；用户可逐张编辑。旧版备份仍可导入，新状态也可导出和再次导入。

## 实现选择与边界

采用从当前 `PortfolioMatrix` 在页面内计算的纯汇总函数。它与编辑状态使用同一份数据，减少另存一套统计结果造成的不一致；无需新行情接口或新的持久化结构。另一种服务端预计算方式增加同步点，对单机即时汇总没有收益。汇总是用户填写的仓位备注之和，不是持仓成本、市值或盈亏。多币种输入、细分日韩台印国家、期权名义金额及更复杂金额格式留待后续版本。

## 验收口径

1. 新建或编辑期权卡片后显示蓝色，并在刷新、重开、导出／导入后保持状态。
2. 灰色和绿色的 `1.5k`、`10k` 计为 11,500 美元；黄色或蓝色同备注不增加普通总额。
3. 纯文字、`put 115`、区间、裸数字不计入；编辑金额或状态后顶部与格子小计同步更新。
4. 按策略、地区、主题的拆分各自等于普通总额；同一格的小计只包含对应主题和地区。
5. 桌面及窄屏页面均不发生横向溢出，原有编辑和持久化不退化。

实现复核补充：小计显示保留到美分对应的 `k` 精度；主题和地区的内部组合键无论自定义 ID 是否含冒号都不能合并两个不同格子。
