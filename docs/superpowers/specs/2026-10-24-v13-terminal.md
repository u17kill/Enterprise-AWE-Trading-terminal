# AWE Trading Terminal V1.3 design

V1.3 adds three independently usable surfaces to the existing manual-refresh terminal.

1. Chart Workspace: a movable, editable, removable, locally persisted text note; a horizontal line; price and 52-week range; TTM PE and latest reported revenue/EPS growth when Longbridge supplies them; Bollinger Bands and ATR computed from the displayed candles. Forward PE and fiscal-year PE appear only with a verified EPS denominator and dated methodology.
2. Dashboard: a five-light health check with volatility, breadth, liquidity/credit, crowding, leverage, each carrying editable judgement, evidence, and date. VIX is quote-backed. Twelve macro cards include S&P 500, Nasdaq 100, gold spot, US 10Y yield, Dow, Bitcoin, Nikkei 225, KOSPI, Shanghai Composite, Hang Seng, Hang Seng Tech, CSI A500. Nikkei 225 and KOSPI were initially unsupported; later fixes add actual index-level snapshots and up to 30 trading days of index trend from the public DeanFi dataset, with market date and explicit third-party attribution. These are daily trends, not intraday charts. Gold now uses Standard Bullion for both its visible wholesale ask quote and 24-hour spot trend, with Gold API as quote-only fallback. Missing or stale feeds stay unavailable with a source-specific explanation. Daily US 10Y data can come from the Treasury. No ETF is mislabeled as its reference asset.
3. Portfolio Map: editable lanes and position cards; symbol/name/currency/share count/unit cost; native-currency cost total. Private browser storage and JSON import/export. Initial import is restricted to actual held common shares, excluding plans, options, ETFs and funds; historical source data requires review before saving. No personal holdings enter the public repository.

All remote credentials remain server side. Manual refresh remains the only network-triggering market action. Each displayed value shows its data date and source. Missing values are not presented as zero or as example data.
