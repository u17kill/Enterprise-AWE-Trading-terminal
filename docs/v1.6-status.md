# V1.6 · 指标大全卡片排序

日期：2026-11-03。状态：首版已开发并在本机预览，待用户验收。

- **需求：**仅在指标大全的同一类别内拖拽移动指标卡片，自由决定位置；顺序在一台电脑上持久保存。详见 [需求草案](superpowers/specs/2026-11-03-v16-indicator-order-design.md)。
- **已交付：**指标大全的宏观先行、美股风险、A 股资金与情绪三类卡片分别排序；可抓住卡片上方的手柄拖动，也可用上下按钮逐位调整。每类可恢复默认顺序，占位卡始终在末尾。调整后顺序保存在本机文件 `Documents/Codex/.awe-terminal-data/canary-order.json`；同机刷新、重开及本地端口切换可读取。保存失败会恢复原顺序并提示。新增指标会排在已有自定义卡片之后。
- **后续修复：**浏览器实测发现原生拖放未可靠触发，改为指针拖动；窄窗口实测拖动、刷新保留及恢复默认均正常。指标数据刷新不会重排卡片。
- **数据与部署限制：**沿用指标大全当前的数据源与缺口；排序不改变指标计算。多台电脑同步移至后续迭代，本期不引入产品账户或同步服务。
- **验证：**V1.6 四个针对性测试文件共 9/9 通过，涵盖分类内移动、单机文件往返、非法替换拒绝、保存失败恢复、重开及行情刷新后保持顺序；TypeScript、全仓 ESLint、Next.js 生产构建通过。3103 浏览器实测拖动、刷新保留、恢复默认；358px 视口没有横向溢出。
- **全套测试边界：**227 项中 222 项通过、5 项失败。其中 2 项旧版国际行情固定数据测试在未修改的 V1.5 分支上同样失败；另 3 项持仓地图测试在全套并行负载下超时，单独运行时 7/7 通过。不能宣称全套测试通过。
- **验收：**用户尚未验收 V1.6；3103 为独立预览，不影响 3102 的 V1.5 页面。
