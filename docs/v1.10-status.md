# V1.10 · 最新风向策展升级

日期：2026-11-09。状态：开发验证中，待用户验收。

- **需求：**按人物组织最新观点，覆盖宏观、价值、科技投资、科技产业、央行与政府六类。沿用终端既有浅色 UI，展示 11 条本期主线、分类温度、人物卡、搜索和立场筛选。详见 [设计](superpowers/specs/2026-11-09-v110-latest-voices-curated-design.md)。
- **交付：**导入 DeepSeek 参考项目 2026-11-08 策展快照的九个分片，合并为 125 人、448 条要点。保留原始文字、日期和来源名称；人物 ID 中的下划线在读取时规范为连字符。首页和“更新策展数据”都由服务端读取分片并重算统计与新鲜度；失败时页面保留旧快照。每人一卡，支持全部要点搜索、偏多／中性／偏空筛选、只看第一条要点、分类跳转和超过 30 天提示。
- **数据边界：**快照没有逐条原文 URL，用户选择先完整导入并明确标注。页面全局和每张卡均写明“策展内容，原件未逐条核验”；来源名称不伪装成可点击原件。按钮重读本地文件，**不从互联网抓取新观点**，也不自动写作或翻译。本期不提供买卖建议或综合情绪指数。抽查结果见 [十条来源审计](v1.10-source-audit.md)，其中有具体数字、日期仅部分吻合的条目，须后续修订。
- **校验：**构建前检查九分片、必填字段、分类与分组、立场、日期、人数和要点数；页面重读时执行更完整的结构校验。空要点、超长与超出窗口日期作为提醒。本版本不把结构校验通过等同于事实核验。
- **验证：**3 个定向测试文件共 8 项通过，覆盖合并、统计、异常数据、搜索、筛选、压缩、分类跳转、刷新失败保留内容及接口每次重读。TypeScript 与改动文件 ESLint 通过；Next.js 16 webpack 生产构建通过，`/voices` 和 `/api/voices` 均为动态路由。构建前数据校验通过：125 人、448 条要点、11 条主线。九个导入分片与提供的原文件逐个 SHA-256 相同。本地 3107 预览的页面及 API 均返回 HTTP 200，API 返回 125 人、448 条、六类、11 条主线、零结构警告；浏览器中 1440px 与 390px 宽度均渲染 125 张卡，文档宽度等于视口宽度，没有横向溢出。见 [桌面截图](v1.10-preview-1440.png)和[窄屏截图](v1.10-preview-390.png)。尚待用户验收。
- **后续：**逐条补原文链接并修订抽查中发现的疑点；策展数据的更新仍需人工完成。
