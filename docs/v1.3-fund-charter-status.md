# V1.3 · 基金宪法

日期：2026-10-31。状态：已实现，待用户在 3101 验收。

GitHub 记录：[草稿 PR #18](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/18)，基于 V1.2 分支。

## 已定需求

- 采用[全局顶栏右侧入口](superpowers/specs/2026-10-31-v13-fund-charter-design.md)，在各功能页面常驻展示。
- 入口高于普通左侧功能栏目，延续现有蓝白浅色视觉风格。
- 点击进入独立 `/charter` 阅读页。
- 用户提供并确认《Enterprise / AWE 投资十大信条 · Core Investment Principles V1.0》全文及阅读式布局：总纲、四大支柱、十条信条、最终投资准则。

## 交付与边界

- 全部十条按原文顺序展示。风险上限为单一标的买入金额不超过总账户资产 3%，单一产业共同风险因子暴露不超过总账户资产 25%。
- 目录可跳到各支柱及最终投资准则；在窄屏上改为正文上方横排目录。
- 总览、图表、持仓、日历、新闻、大佬持仓、期权、大师哲学、金丝雀及投资框架页面的顶栏均有基金宪法入口，左侧普通导航没有该入口。
- 本期只展示静态文稿，不提供编辑、下载或根据条款自动下单等功能；正文 V1.0 与终端 V1.3 是不同版本号。
- 本记录与 2026-10-24 的旧 `docs/v1.3-status.md` 是不同主题；保留旧记录原样。
