# V1.7 · 持仓地图汇总与蓝色期权

日期：2026-11-03。状态：已开发并在 3104 本机预览，待用户验收。

- **需求与口径：**持仓地图增加蓝色期权状态；顶部显示普通仓位总额及按策略、地区、主题拆分的美元小计；地图中策略、主题、地区及主题 × 地区格子显示就地小计。只计算灰色“已持仓”和绿色“计划加仓”中完整的 `1.5k` 类备注。用户明确确认现有可计算数字统一按美元处理。详见 [V1.7 设计](superpowers/specs/2026-11-03-v17-portfolio-totals-design.md)。
- **交付：**蓝色期权可在卡片编辑框选择，图例、卡片和顶部期权列表同步更新。黄色观察和蓝色期权均不进入普通总额；期权只显示张数、代码及原始备注。裸数字、区间、纯文字和 `put 115` 等非完整 `数字k` 备注不计入。无可计算金额的类别显示“—”，有效 `0k` 显示 `$0`。原有卡片不根据文字自动改状态，避免误改用户数据。
- **代码复核修复：**保留 `1.234k` 等备注的完整美元精度，避免小计显示成少 4 美元的 `$1.23k`；格子汇总使用不冲突的主题／地区组合键，避免自定义 ID 含冒号时误合并。
- **保存与兼容：**沿用现有本机持仓地图文件、浏览器恢复逻辑及 JSON 导入导出；旧状态保持原样，新期权状态也可保存和导入。3104 与此前预览共用用户的本机持仓文件；隔离编辑验证使用独立数据目录和 3105 端口，完成后已关闭。
- **数据限制：**汇总是用户填写的美元仓位备注之和，不是实时市值、盈亏或经核验的持仓。地图当前“日韩台印”仍为合并地区，不能细分为各国；多币种和期权名义金额不在本期。
- **验证：**最终代码的持仓地图与持久化相关的 4 个测试文件共 19/19 通过；TypeScript、全仓 ESLint、Next.js 生产构建通过。3104 浏览器检查顶部汇总和各层小计；375px 窄屏页面无横向溢出。3105 隔离数据实测将一张普通卡片改为蓝色期权后，普通总额同步扣除对应金额、期权数增加，刷新后蓝色状态及两项汇总均保留。
- **全套测试边界：**最终代码限制并行数后的全套 235 项中 231 项通过、4 项失败：2 项旧版国际行情固定数据测试在 V1.6 基线已失败；1 项旧持仓地图测试超时，另 1 项旧导入测试仅在并行全套运行时未等到导入完成。持仓地图测试文件单独运行 9/9 通过。不能宣称全套测试通过。
- **界面预览：**[隔离演示数据截图](v1.7-portfolio-preview.png)；演示图使用默认种子地图，不含 3104 的当前用户持仓。正式预览为 `http://127.0.0.1:3104/portfolio`。
