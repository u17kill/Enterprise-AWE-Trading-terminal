# V1.12 全站 UI 优化交付记录

状态：实现完成，待用户验收。设计依据：[全站优化方案](sitewide-ui-optimization-proposal.md)。

## 需求与范围

覆盖侧栏全部 16 个入口：总览看板；金丝雀的指标大全、市场温度、估值分析、短线精灵；市场情报的市场动态、最新风向、财经日历、大佬持仓、机构研报；投资工具的图表空间、持仓地图、期权计算；投资学堂的投资框架、大师哲学、基金宪法。用户要求字体随浏览器窗口收放。只调整 UI，不改变功能、数据、保存、筛选或计算。

## 已做

- 在全局样式后追加统一视觉尺度：页面标题、关键数值、正文、来源及操作字号随窗口宽度适度变化，保持蓝白主题。
- 统一页面内容边距、卡片圆角、操作按钮与表格/矩阵的滚动边界；桌面多列，中宽合并，窄屏单列。
- 总览资产卡保持同高、固定走势图与来源区域；金丝雀指标卡、研究卡和持仓读数使用一致的文字层级。
- 图表空间顶部更新按钮与链接区分离，窄屏链接区在自身容器滚动；右侧信息在窄屏进入主图下方。
- 持仓核心基金卡高度跟随内容；卫星卡字体随宽度调整，矩阵仍可局部横向滚动。
