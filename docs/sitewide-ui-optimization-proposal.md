# Enterprise AWE 全站 UI 优化方案（待用户核对）

范围：网站现有全部页面。视觉稿：<http://127.0.0.1:3110/>。左侧每个入口均可点击，按页面类型显示示意内容；仅为视觉与布局核对，不是真实功能页面。确认后再进入正式开发。

## 页面盘点

- 总览看板 1 页。
- 金丝雀指标 4 页：指标大全、市场温度、估值分析、短线精灵。
- 市场情报 5 页：市场动态、最新风向、财经日历、大佬持仓、机构研报。
- 投资工具 3 页：图表空间、持仓地图、期权计算。
- 投资学堂 3 页：投资框架、大师哲学、基金宪法。

共 16 个导航入口；Chart Workspace 动态代码页沿用同一设计规则。实际实现按页面类型处理：行情卡、指标卡、新闻/人物、日历、表格与侧栏、图表/计算器、持仓编辑、长文/原图。每页仍保留自身必要布局。

## 扫描结果

现有样式分布在 17 个 CSS 文件，大量模块独立定义字号和断点。源码扫描检出多个文件含 9–12px 标签、来源、说明和按钮；其中金丝雀研究、最新风向、机构研报、期权计算最密集。页面已有多套 420–1380px 断点，但同一类卡片的留白、圆角、标题和按钮高度不一致。单一全站字号覆盖会压坏图表、矩阵和表格，因此采用共用尺度加页面局部修正。

DeepSeek 参考页可借鉴的做法：先概览后细节、关键数值与来源清晰分层、总仓/子仓拆解、观点和实时读数分开。其较长顶部说明与横向顶栏在小窗口下过于占位，不纳入当前方案。

## 提案

1. 以窗口宽度驱动字号：标题约 23–34px，关键数字约 20–36px，普通正文约 12–15px，密集表格与来源约 10–12px。使用 `clamp()` 和明确断点；小窗口收紧但关键操作仍可辨读。保留浏览器自身缩放和用户字号设置，不强制固定像素。
2. 全站统一页面头部的层级、控件高度、卡片圆角与 8px 间距阶梯。保留蓝白基调与持仓四色，不改变品牌标识。
3. 屏宽超过 1150px 时多列；中间宽度收成两列；约 740px 以下主内容单列。表格、矩阵只在自身容器横向滚动，页面整体不左右漂移。
4. 总览：资产卡数值、涨跌、走势图和来源固定位置，四列随宽度变两列/一列。
5. 金丝雀：四页共用市场切换、筛选、指标卡、图表/解释样式；让状态和日期在卡片上有固定位置。
6. 情报：新闻、人物、研报统一来源与日期层级；机构目录/详情面板中间宽度保持可用，手机顺序上下排列；日历手机格仅保留数量并在下方展开事件。
7. 工具：图表主图区与右侧信息分离，窄屏将侧栏移到图下；期权输入区和盈亏图采用同一操作字号；持仓判断/实时读数分栏，矩阵在窄屏按策略/主题/地区阅读。
8. 学堂：长文限制行长，标题、引言、引用、人物头像和目录统一阅读节奏；投资框架原图完整显示并可缩放。

## 功能边界与验收

不更改数据源、计算公式、保存方式、导航目标、筛选行为、交互和全文内容。开发后逐页检查 16 个入口在 1440、1024、390px 下的可读性与整页溢出，重点复核图表、表格、编辑弹层以及现有持仓保存与指标刷新流程。
