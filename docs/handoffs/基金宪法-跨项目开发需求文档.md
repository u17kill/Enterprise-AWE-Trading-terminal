# 基金宪法：功能复刻需求文档（含全部文字数据）

交付对象：在另一个网站/地址开发类似功能的模型或开发者。整理日期：2026-11-26。依据：Enterprise / AWE Trading Terminal V1.17 当前实现。

**这是当前功能的独立交接文档，不需要读取原聊天、原仓库或原本机服务即可理解需求。新网站可以沿用自己的技术栈和视觉语言，但不得漏掉正文、入口及保存保护。**

## 1. 模块定位与范围

模块名称：基金宪法。用于集中阅读、维护一份基金的核心投资原则。它的层级高于普通业务工具，是长期约束投资行为的纲领。

本期是“一份宪法，多个支柱，每个支柱包含多条信条”。支持在现有宪法中新增和编辑，不是多文件知识库，不是PPT或图片展示页，不只是把十条正文写死在代码里。

初始内容：四大支柱、十条信条、总纲和最终投资准则。首次进入默认阅读模式。正文全部保留，编辑由用户主动进入。

## 2. 入口位置与路由

- **不放到左侧栏作为普通一级/二级菜单。** 原用户明确认为该模块级别较高。

- 当前网站在市场总览、金丝雀相关研究页、市场情报页、投资框架及大师哲学等页面的顶部操作区复用该入口；不需要强行给此前取消顶栏的页面增加一整条工作台顶栏。

## 4. 文案、编号和数据结构

- 编辑元信息：页面标题、副标题、总纲、最终准则标题及全文。
- 页面标题可以自定义；留空时，恰好十条显示“投资十大信条”，其他条数显示“投资信条”。不能新增第十一条后仍固定叫十大。
- 条数和支柱数实时计算；支柱编号从01开始，信条编号跨所有支柱连续从01开始。排序/移动/删除后自动重新编号。
- 支柱、信条使用稳定唯一ID，不能把名称或显示序号作为唯一键；改标题不应断开关联或改变目录定位。
- 正文为纯文本，多段正文按空行拆分；要点每行一项；不要执行用户输入HTML/脚本。

推荐结构（配套JSON已按此结构附上）：

```ts
type Principle = {
  id: string;
  title: string;
  paragraphs: string[];
  bullets?: string[];
  afterBullets?: string;
  conclusion: string;
};
type Pillar = {
  id: string;
  name: string;
  english: string;
  principles: Principle[];
};
type CharterDocument = {
  schemaVersion: 1;
  title: string; // 空字符串表示自动标题
  subtitle: string;
  manifesto: string;
  pillars: Pillar[];
  finalTitle: string;
  finalParagraphs: string[];
};
```

## 5. 编辑交互

### 5.1 进入和退出

阅读页点击“编辑基金宪法”后显示管理操作。按钮变成“预览”，可切回干净阅读视图；切换模式不丢弃改动。修改先保留为草稿，“应用到页面”和“保存全部修改”必须区分。

### 5.2 支柱

- 新增支柱：中文名称必填、英文名称可选；新增后排在末尾。
- 编辑名称；上移/下移调整顺序，首尾对应按钮禁用。
- 删除支柱需确认，并明确其中多少条信条会一起删除。
- 支柱可以暂时没有信条，显示新增引导。

### 5.3 信条

- 在全局工具栏或某支柱下“新增信条”。
- 表单字段：所属支柱、信条标题、多段正文、可选要点列表、可选要点后补充、可选条目总结。
- 标题必填，其余正文允许用户留空；所属支柱必须存在。
- 可修改全部字段；所属支柱下拉选择实现跨支柱移动，同支柱编辑保持原位置，换支柱后追加到目标支柱末尾。
- 可上移/下移调整同支柱内顺序；可单独删除并确认。

### 5.4 表单

采用右侧编辑抽屉或等价清晰编辑界面。字段说明明确“段落间空一行”“要点每行一条”。操作包括“应用到页面”“取消”“导出当前草稿”。

应用前校验，失败在表单内提示，不清空输入；应用后更新页面草稿并关闭抽屉，不直接写源文件。取消时若文字已改变需要确认。Esc可取消，Tab焦点保持在抽屉内，关闭后焦点回到触发位置。

## 6. 保存、恢复与迭代保护（必须实现）

### 6.1 文件保存

最重要的规则：**用户最新保存的正文优先，后续代码迭代、刷新、重启不能把内容还原成种子。**

当前实现是本机服务端文件 fund-charter.json，存放在源码外稳定目录，而不是打包产物或临时预览目录。原站默认 C:/Users/T14s/Documents/Codex/.awe-terminal-data/fund-charter.json；新站使用自己的稳定目录或持久数据库，不要求照抄这个绝对路径。

仅在没有保存文件时提供本附录初始正文。读取失败或文件损坏不能当作“没有文件”，不能静默重置。读取页面不应主动重写文件。点击“保存全部修改”成功才显示已保存状态；失败必须保留编辑，并允许重试/导出。

保存前备份旧文件，原站保留最近30份；临时文件写入完成后原子替换。进程间写入需排他，进程异常退出不应永远阻塞后续保存。存储目录随部署和重建保持不变，备份也不放在会被重建覆盖的目录。

### 6.2 浏览器草稿

输入时包括“尚未应用”的抽屉文字都自动保留浏览器草稿。刷新后恢复本页草稿，明确提示尚未写入文件。复制标签页需使用独立写入键，不相互覆盖。旧页/其他页草稿提供手动恢复，不自动抢占新文件。保存一个页面不得清掉另一页面仍在输入的草稿。

浏览器存储失败时，明确提示“改动只在当前页”，提供保存和导出；离开/刷新时提醒。草稿属于当前站点的浏览器存储，不会因为另一个地址也叫基金宪法就自动共享。

### 6.3 并发冲突

读取时获得revision（例如文件内容SHA256）；保存携带读取版本。文件已被其他页修改时返回409，不最后写入者无提示覆盖。保留两份，提供“使用文件内容”“用本机草稿覆盖文件”。覆盖必须是用户主动选择，而且仍需针对最新版本再校验；覆盖旧文件前备份。选文件前先保留当前草稿；无法保留时阻止丢弃并提示先导出。

### 6.4 状态

至少区分：初始文稿尚未写文件；有未保存修改且草稿已保留；仅当前页未保留草稿；正在保存；保存成功与时间；保存失败；版本冲突；读取失败。不要仅凭点击按钮就显示成功。

## 7. 导入、导出与新地址迁移

- 导出JSON备份，内容包含完整文稿；抽屉有未应用输入时，导出须同时包含form和revision，避免遗漏文字。
- 导入支持完整文稿对象，或包含document的备份包装。格式验证通过后仍需用户确认，先载入为草稿，检查后再保存，不直接覆盖文件。
- 畸形表单字段不能导致运行时崩溃；可拒绝备份或忽略不完整表单，但不得静默丢弃有效正文。
- 新地址首次开发可直接读取配套“基金宪法-完整初始数据.json”；文件与本附录正文一致。
- 两个站点默认各自独立保存。**本需求不要求它们实时同步。** 若以后要共享最新修改，需显式连接共同服务端数据源并约定权限和冲突处理，不能只共用localStorage键名。

## 8. 接口建议及校验

原站：GET /api/fund-charter 返回 {ok,document,revision,updatedAt}，PUT同路径提交 {document,revision}，成功返回新快照及备份信息。返回禁止缓存。新站可采用等价接口。

参考校验：schemaVersion=1；最多50个支柱、共500条信条；ID只允许英数字/下划线/连字符且全局唯一，保留final-principle作为最终准则锚点；名称与标题非空；标题200/信条标题300字上限；单段正文20000字以内、列表最多100段；文件/请求最多1MB。校验应覆盖浏览器和服务端。

本机版仅接受同源本机保存，校验Origin协议、主机和端口，拒绝cross-site。框架可能把内部URL规范成localhost而浏览器使用127.0.0.1，应正确使用经过白名单校验的外部Host比较，不能因此让正常保存全被拒绝。如果新站对外部署，必须适配自己的访问控制和可信域名，不能直接删除校验放开任意写入。

错误应有可理解提示：400格式、403来源、409冲突、413过大、429正在保存、500损坏文件、503存储不可用。实现方式不强制，但不可把失败当成功。

## 附录A：现有完整文字数据（必须全部导入）

核验时原站尚未创建人工修改后的fund-charter.json，因此以下为当前页面采用的原始四支柱十信条全文。没有混入开发验证用的第11条或测试标题。

页面标题：投资十大信条（自动标题）  
副标题：Core Investment Principles · V1.0  
**总纲：先求生存，再求收益；以价值为锚，以纪律为尺，以组合为舟，以时间为友。**

### 第一支柱：生存与风险控制

*Survival & Risk Management*

稳定ID：survival

#### 01｜结构的价值：让组合穿越周期

优秀的投资组合，不是简单地把收益最大化，而是通过不同资产与风险来源的合理配置，降低单一周期、单一产业和单一判断对整体资产的冲击。

好的组合结构，让我们在市场上涨时能够参与，在市场下跌时能够承受，在长期波动中依然有信心持有。

**组合的最终价值，是帮助我们活得更久、拿得更稳，让长期复利真正发生。**

#### 02｜仓位的纪律：永远保留生存的权利

承认判断可能出错，也承认市场可能出现无法预见的极端情况。

坚持明确的风险边界：

- 单一标的买入金额不超过总账户资产的 3%。
- 单一产业共同风险因子暴露不超过总账户资产的 25%。

不允许一次判断失误破坏整个投资体系。再好的机会，也不值得用基金的生存作为赌注。

**仓位控制不是限制收益，而是防止永久性损失和致命错误。**

### 第二支柱：价值与认知

*Value & Understanding*

稳定ID：value

#### 03｜识别价值：研究价值，而不是猜测价格

短期价格走势难以可靠预测，但资产内在价值可以通过宏观、产业、商业模式、盈利能力与未来现金流进行有依据的估计。

把主要精力放在理解资产的价值创造能力上，而不是预测市场明天上涨还是下跌。

价格是交易的结果，价值是投资判断的锚。

**少猜价格，多研究价值；不为波动改变信念，只为价值变化修正判断。**

#### 04｜估值的力量：好资产也必须有好价格

估值是投资决策中不可放弃的纪律。

再伟大的公司，如果买入价格过高，也可能带来长期低回报。

关注价格与内在价值的差距，理解估值倍数的扩张和收缩，重视合理估值中枢及均值回归的可能性。

但估值中枢可能因增长、利率、风险与企业质量发生结构性变化，不能机械地认为历史均值永远正确。

**尊重估值，保持安全边际，不为优秀的故事支付无限的价格。**

#### 05｜坚守能力圈：看不懂，就不碰

不投资自己无法理解的资产。

对于存在重大疑问的公司，不因价格上涨、市场热度或他人观点而匆忙买入。

看不懂，就深入研究；研究后仍然看不懂，就果断放弃。

承认认知边界，不把无知包装成信念。

**机会可以错过，本金不应该浪费在自己无法理解的风险上。**

### 第三支柱：纪律与人性

*Discipline & Behavioral Control*

稳定ID：discipline

#### 06｜逆向思考：身处市场，冷眼旁观

当市场极度乐观时保持警惕，当市场极度悲观时主动寻找机会。

不因为所有人都看好而贪婪，也不因为所有人都恐惧而绝望。

尊重市场传递的信息，但不让市场的情绪决定自己的行为。

逆向投资不是机械地与市场作对，而是在情绪极端时独立判断价格和价值是否发生错位。

**限制贪婪，克制恐惧，敬畏市场。身处其中，冷眼旁观。**

#### 07｜耐心的奖励：买前等待，买后坚守

耐心是投资者最重要、也最稀缺的能力之一。

买入之前，耐心等待合理估值和良好的风险收益比，不因FOMO而追高。

买入之后，只要长期价值逻辑仍然成立，就给予企业成长和价值兑现足够的时间。

不因市场短期没有奖励自己，就怀疑一项经过充分研究的投资。

**买前耐心等待好价格，买后耐心等待价值显现。越急躁，越容易犯错。**

#### 08｜机会永远存在：错过不是损失

市场永远存在新的机会，不必抓住所有上涨，也不必参与每一个热门主题。

真正具有吸引力的投资，往往出现在优质资产暂时被市场忽视、悲观预期过度反映到价格之时。

错过机会是策略必须承担的成本，追逐所有机会则可能使投资者承担无法控制的风险。

**宁愿错过看不懂的上涨，也不为了害怕错过而放弃纪律。**

### 第四支柱：远见与长期复利

*Long-Term Vision & Compounding*

稳定ID：compounding

#### 09｜看远一点：大钱来自远见、价格与时间

长期投资的重要优势，是能够在短期噪声中识别尚未充分反映的长期变化。

宏观趋势、产业革命、竞争格局和企业价值创造，往往需要多年才能充分展开。

真正可观的投资收益，常常来自较早理解长期趋势，在合理甚至低估的价格买入，并给予价值足够长的兑现时间。

**看得远，买得合理，拿得住，才能有机会赚到长期复利的钱。**

#### 10｜相信长期增长：站在价值创造的一边

长期保持对人类发展、科技创新和经济价值创造的建设性乐观。

我们关注三股长期力量：

- 宏观发展：生产率、制度改善、资本积累与经济增长。
- 技术革命：科技进步创造新产业，提高效率，扩展经济边界。
- 价值累积：优秀企业持续创造现金流，合理配置资本，并回报股东。

这些力量是长期投资的重要基础，但不意味着任何国家、行业或股票都必然持续上涨。

**相信长期创造价值的力量，把资本配置到能够持续分享增长成果的资产上。**

### AWE 的最终投资准则

**生存优先于暴利，价值优先于价格，纪律优先于情绪，长期优先于短期。**

我们不追求每一次交易正确，不试图捕捉每一次上涨，也不幻想规避所有回撤。

我们追求的是一套能够反复执行、容许错误、控制损失，并在长期持续积累回报的投资体系。

Understand Value. Respect Price. Protect Capital. Stay Invested. Let Time Compound.

理解价值，尊重价格，保护资本，长期在场，让时间创造复利。
