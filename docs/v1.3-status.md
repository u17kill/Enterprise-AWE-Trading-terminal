# V1.3 需求与交付记录

2026-10-24。承接 V0.2 的手动更新模式，新增三个页面能力。实现和验收细节见 `superpowers/specs/2026-10-24-v13-terminal.md`。

## 已交付

- 总览看板：默认 12 张宏观资产卡片；五灯模型可编辑灯色、依据和日期，VIX 显示报价；黄金现货报价及走势优先用 Standard Bullion，Gold API 作为仅报价备选；BTC/USD、美国十年期国债收益率分别由 Coinbase Exchange、美国财政部提供，卡片注明来源与观察时间。Longbridge 支持的美港 A 指数及股票展示真实报价；休市后的走势图取最近交易日 5 分钟 K 线，不用固定图片。
- 图表空间：水平线、可编辑且可移动的文字便签；布林带和 ATR；52 周区间；个股 TTM PE、最近财政年度静态 PE、市净率、股息率、最新季度营收/EPS 同比。财报及年度 EPS 都标注期间，图表绘图保存在当前浏览器。
- 持仓地图：可增删改通道和正股持仓，卡片包含代码、名称、股数、每股成本、投入总额，按原币种分别合计；本地保存及私人 JSON 导入/导出。本机历史快照只供逐笔预览，经手动核对和确认才会导入。个人持仓文件位于 Git 忽略的 `.local/`，不进入公开仓库。

## 已知数据边界

- 日经 225、KOSPI 的指数价格和近 30 交易日日线走势已在后续 bug 修复中接入公开第三方数据集；尚无同源盘中分时 K 线。没有用 ETF 冒充指数。
- 黄金现货源提供首页近 24 小时价格走势，但图表空间的 OHLC 历史 K 线仍待接入。Gold API 备选只提供报价，触发备选时首页明确显示走势不可用。
- 标普 500、纳斯达克 100 的 TTM/前瞻 PE 及个股前瞻 PE 需要期间和分母明确的数据源。暂不展示估算值。
- 标普 500 成分股 MA50/MA200 市场宽度仍需完整成分股及足够历史，五灯里的该维度暂由用户人工判断。
- 组合地图只存于当前浏览器；用户需要定期导出私人备份。公开部署前还需为 Longbridge OAuth 建立持久且加密的每用户服务端会话。

## 2026-10-27：走势图仍为空的复报

- 上一次只核对了三张卡的**价格**，却把 bug 误报为整体修复；用户明确指出缺的是**走势图**。复查 3101 页面确认：黄金、日经、KOSPI 的价格存在，但三个走势框仍为空。
- 日经和 KOSPI 现用同一 DeanFi 数据仓库的[指数历史文件](https://github.com/DeanFinancials/deanfi-data/blob/main/major-indexes/international_major_indices_historical.json)，取最多 30 个真实交易日的指数收盘数据，再接入当日已发布的指数快照。缺价或陈旧历史不绘制，卡片明确标为“近30交易日指数走势”，不称分时。
- 黄金改用 [Standard Bullion 免费现货数据](https://standardbullion.com/gold-price-api)作为首页首选：同一提供商的黄金卖出价和近 24 小时记录绘图，卡片直接显示其要求的“Data by Standard Bullion”署名。该报价是其批发卖出价，不等同于 Gold API 的单一参考价；Standard Bullion 失败时退回 Gold API 报价并如实显示走势图不可用。图表空间的 OHLC K 线仍未接入。
- 用户 Chrome 的 3101 页面再次手动刷新后，三张卡**都显示实际 SVG 走势曲线**，且黄金曲线末点与卡片报价一致；截图目视核对日经、KOSPI 曲线均非空。
- 完整回归：**34 个文件、147 项测试通过**；`pnpm lint` 与 `pnpm build` 通过。修复和数据边界同步记录在 [PR #13](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/13)。
