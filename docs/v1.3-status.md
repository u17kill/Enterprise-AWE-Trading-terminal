# V1.3 需求与交付记录

2026-10-24。承接 V0.2 的手动更新模式，新增三个页面能力。实现和验收细节见 `superpowers/specs/2026-10-24-v13-terminal.md`。

## 已交付

- 总览看板：默认 12 张宏观资产卡片；五灯模型可编辑灯色、依据和日期，VIX 显示报价；黄金、BTC/USD、美国十年期国债收益率分别由 Gold API、Coinbase Exchange、美国财政部提供，卡片注明来源与观察时间。Longbridge 支持的美港 A 指数及股票展示真实报价；休市后的走势图取最近交易日 5 分钟 K 线，不用固定图片。
- 图表空间：水平线、可编辑且可移动的文字便签；布林带和 ATR；52 周区间；个股 TTM PE、最近财政年度静态 PE、市净率、股息率、最新季度营收/EPS 同比。财报及年度 EPS 都标注期间，图表绘图保存在当前浏览器。
- 持仓地图：可增删改通道和正股持仓，卡片包含代码、名称、股数、每股成本、投入总额，按原币种分别合计；本地保存及私人 JSON 导入/导出。本机历史快照只供逐笔预览，经手动核对和确认才会导入。个人持仓文件位于 Git 忽略的 `.local/`，不进入公开仓库。

## 已知数据边界

- 日经 225、KOSPI 仍待找到可核验的指数源。没有用 ETF 冒充指数。
- 黄金现货源只提供报价，没有可靠的相同来源分时和历史 K 线。
- 标普 500、纳斯达克 100 的 TTM/前瞻 PE 及个股前瞻 PE 需要期间和分母明确的数据源。暂不展示估算值。
- 标普 500 成分股 MA50/MA200 市场宽度仍需完整成分股及足够历史，五灯里的该维度暂由用户人工判断。
- 组合地图只存于当前浏览器；用户需要定期导出私人备份。公开部署前还需为 Longbridge OAuth 建立持久且加密的每用户服务端会话。
