# V0.9 市场健康仪表盘记录

## 需求与决定

用户确认总览看板采用两行、每行五卡的市场健康仪表盘：第一行五灯使用显眼的圆形指示灯；第二行分别以迷你走势、双线、比例条和半圆指针展示 10Y–2Y、等权表现、Put/Call、恐慌贪婪，最后一格预留。仪表盘有自己的“重新计算”按钮，只在点击时更新。保存最后一次数据，局部失败保留旧值和原日期。五灯口径参考旧周报，界面设计见[设计文档](superpowers/specs/2026-10-26-v09-market-health.md)。

实施代码与评审见[草稿 PR #13](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/pull/13)，需求追踪见[Issue #12](https://github.com/u17kill/Enterprise-AWE-Trading-terminal/issues/12)。

用户口头称“CNBC 恐慌贪婪”，核对后使用实际发布该股市指标的 **CNN Business Fear & Greed**，页面和来源都明确写 CNN；不把 CNN 值称为 CNBC。人工五灯判断和文字继续保留为独立备注，自动颜色不会被人工颜色覆盖。

## 当前交付

- 新增 `/api/market-health` 按需服务端接口，FRED、CNN 和已连接的 Longbridge 并行获取；单源失败不会清空其他卡。Longbridge 令牌继续只在服务端会话中，浏览器仅保存公开指标和人工备注。
- VIX 使用旧周报 <20 / 20–30 / >30 的灯色；高收益债 OAS 使用 <4 / 4–5 / >5，并对四周扩大超过 100bp 标红。杠杆用芝加哥联储周度 NFCI 杠杆子指数过去 52 周分位，**70% / 90% 为本项目参考阈值，并非旧周报原阈值**。
- 拥挤度用 SPY 期权 Put/Call 量比过去约 260 个交易日的分位；这是代理指标，不冒充 CFTC 头寸或综合拥挤度。第二行的 Put/Call 同样明确为 SPY；等权对比用 RSP/SPY 两只 ETF 同日起点归一化。
- 桌面五列两行布局，窄屏重排。数值、解释、来源、原始发布日期和“旧数据”状态均直接在卡上。CNN 指标为发布值，指针显示 0–100 位置。

## 数据限制与后续修复

- **市场宽度仍待完整数据**：Longbridge 当前 `constituent` 对 `.SPX.US` 报告总数 501，但实际只返回 20 个项目；无法据此算所有标普 500 成分股位于 MA50/MA200 上方的比例。卡片保持灰灯并说明原因，不把当日上涨家数误称均线宽度。补全后按旧周报 >60%、40–60%、<40% 规则计算。
- VIX 期限结构、CFTC 头寸、FINRA 月度保证金债务尚未接入；当前对应卡用已标注的单一代理指标或只按 VIX 现值评分。五灯不等权，不能将单灯颜色当成买卖信号。
- FRED OAS 与 10Y–2Y 是日度，NFCI 杠杆是周度。显示实际发布日期，不称实时数据。CNN 页面使用的 JSON 端点未提供稳定公开 API；若其结构或访问策略改变，保留旧值并显示失败原因。
- 本地 V0.9 预览使用端口 3101。3101 的 Longbridge 授权需单独连接，测试时未使用用户凭据，所以长桥卡显示待连接。
- 分支复核时发现并修复：SPY 历史样本不足时拥挤度不再显示误导性的 `0`；整次请求失败会把保留的旧卡全部标为旧数据；浏览器拒绝读写本地存储时页面仍能显示新取得的数据（仅本次打开期间保留）；Put/Call 大于 1 时两条比例条按较大值共同缩放。

### 2026-10-26：三个指标仍为空的反馈

- 用户反馈市场宽度、拥挤度和 Put/Call 仍无值。市场宽度属于上述完整成分股数据缺口，**本次未补齐**。已核对 Longbridge 可返回 SPY 期权量的 260 个交易日数据，故后两项不是上游缺少历史数据。
- 最初检查的 Codex 内置浏览器未连接长桥；用户实际使用的 Chrome 已授权。另查出本地 3100 和 3101 原先使用同名 Cookie；浏览器 Cookie 不按端口隔离，两个独立服务的会话标识会相互覆盖。本次将本地 Longbridge Cookie 按端口命名，连接、回调、状态及所有读取会话的 API 统一使用对应名称。服务重启仍会清除内存中的令牌会话，令牌继续只保存在服务端。
- 在用户实际使用的 Chrome 中看到确切错误：SPY 期权量工具返回约 94 KB，被截断为以 `[TRUNCATED` 开头的文本，服务端按 JSON 解析失败，导致拥挤度与 Put/Call 同时为空。已给该工具调用加字段投影，只取时间、Call 量和 Put 量；260 日完整响应约 25 KB。先复现解析失败的测试，再验证修复。
- Chrome 端到端重新计算后，**拥挤度为 78% 分位，Put/Call 为 1.31 倍**，均标注 SPY、Longbridge 和 10/23 数据日期；刷新浏览器后仍可见。本次全量回归为 **34 个文件、137 项测试通过**，`pnpm lint`、`pnpm build` 均通过。市场宽度仍待完整数据源。
- 用户随后决定本地只使用 **3101**，不再使用 3100。开发命令、登录后预览脚本和 README 改为 3101；Windows 计划任务 `AWE Trading Terminal Local Preview` 已核对并改为指向 V0.9 工作目录内的脚本。已确认旧 3100 进程是旧项目 `next start`，停止后只剩 3101 在监听。尚未通过实际重启电脑验证登录触发。
